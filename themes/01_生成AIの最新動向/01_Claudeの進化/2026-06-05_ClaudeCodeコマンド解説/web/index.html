MAP

Claudeのコマンドは「外側」と「内側」で分ける

外側はターミナルから起動するCLI。内側は会話中に使うスラッシュコマンドです。

CLI

外側: 起動するコマンド

claude、claude -p、claude -c のように、会話の始め方や戻り方を決めます。

/

内側: 会話中の操作

/plan、/compact、/diff のように、作業中の状態を切り替えます。

START

まず覚えるCLI: 始める・聞く・戻る

コマンド使う場面
claude対話形式で作業を始める。
claude "query"最初の依頼文つきで開始する。
claude -p "query"1回だけ質問して終了する。自動化向き。
cat file | claude -p "query"ファイル内容を渡して処理する。
claude -c同じフォルダの直近会話を続ける。
claude -r "name"会話IDや名前を指定して戻る。
FLAGS

CLIオプションは「範囲・モデル・権限」を決める

--add-dir

追加フォルダを読めるようにします。

--model

使うモデルを指定します。

--permission-mode

権限確認のモードを指定します。

--allowedTools

許可済みツールを追加します。

--max-turns

自動処理の往復回数を制限します。

--output-format json

結果をJSONで受け取ります。

SETUP

最初の設定は「説明書・記憶・権限」から

1

/init

プロジェクト用のCLAUDE.mdを作る。

2

/memory

いつも使うルールや記憶を管理する。

3

/permissions

許可・確認・禁止を整理する。

4

/mcp

外部ツールや情報源を接続する。

5

/agents

サブエージェント設定を管理する。

6

/config

モデルや表示などの設定を開く。

CONTEXT

会話が長くなったら「計画・確認・圧縮」

/plan大きな変更の前に計画モードへ入る。
/context現在の文脈使用量を確認する。
/compact会話を要約して文脈を空ける。
/clear新しい会話に切り替える。
/btw本筋に混ぜたくない横道質問をする。
/resume過去の会話に戻る。
REVIEW

出す前は「差分・レビュー・安全確認」

基本順序

  • /diff で変更を見る
  • /code-review で正しさを確認
  • /security-review で安全面を見る

修正まで任せる時

/code-review --fix は指摘の反映まで依頼できます。大きな変更では、まず指摘だけ確認するのが安心です。

PARALLEL

並行作業は「背景・分担・確認」で使う

/background / /bg現在のセッションを背景で続ける。
/agentsサブエージェントを管理する。
/tasks背景タスクを見る。
/fork会話を引き継ぐ背景サブエージェントを出す。
/branch会話を分岐して別方向を試す。
/batch大規模変更を分解して並行実行する。
TROUBLE

困った時は「状態・診断・終了」を見る

/help

使えるコマンド一覧を見る。

/status

バージョン、モデル、接続状態を確認する。

/doctor

インストールや設定を診断する。

/debug

ログを有効にして原因調査する。

/usage

利用状況や制限を見る。

/exit

CLIを終了する。

セルフチェック
  • 外側のCLIと内側のスラッシュコマンドを区別できる
  • 長い会話で /compact を使う場面がわかる
  • 提出前に /diff とレビュー系コマンドを使える
GLOSSARY

用語解説

Claude Codeクロード・コード

ターミナルで使うAIコーディング支援ツール。

CLIシーエルアイ

ターミナルで文字を打って操作する入口。

Slash commandスラッシュ・コマンド

会話中の先頭で実行する操作コマンド。

Permissionパーミッション

実行してよい操作の許可範囲。

MCPエムシーピー

外部ツールや情報源をAIにつなぐ仕組み。

Contextコンテキスト

Claudeが参照している会話やファイルの範囲。

Compactコンパクト

長い会話を要約して文脈を軽くする操作。

Diffディフ

変更前後の差分。

Subagentサブエージェント

本体とは別に働く担当AI。
