START

まず覚えるCLI: 始める・聞く・戻る

一言で

普段使いは claude、自動化は -p、続きは -c と -r です。

コマンド使う場面例
claude対話形式で作業を始めるプロジェクトを開いて相談する
claude "query"最初の依頼文つきで開始するclaude "この構成を説明して"
claude -p "query"答えを出して終了するログ要約、簡単なチェック、自動処理
cat file | claude -p "query"ファイル内容を渡して処理する長いログやメモを要約する
claude -c同じフォルダの直近会話を続ける昨日の作業に戻る
claude -r "name"会話IDや名前を指定して戻る複数案件を名前で切り替える
