Claude Code クロード コード

日本語で頼むとファイルを直接読み書きしてくれる AI。今回の制作環境そのもの。

claude.com 🔗
CLAUDE.md クロード エムディー

Claude Code が毎回読む指示書。職場でいう「業務マニュアルの表紙」にあたる。

Anthropic アンソロピック

Claude を開発した米国の AI 安全研究企業（2021年設立）。

anthropic.com 🔗
Markdown マークダウン

記号だけで見出しや箇条書きを表す書式。指示書もこの形式のただのテキスト。

コンテキスト コンテキスト

AI が一度に読める情報の量。増やしすぎると、個々の指示の存在感が薄まる。

エージェント エージェント

AI が自分で判断しながら複数の作業を進める働き方。有能な代行者のイメージ。

ヘッドレスChrome ヘッドレス クローム

画面を出さずに動く Chrome。人が見る代わりに、描いて測るために使う。

SVG エスブイジー

拡大してもぼやけない図の形式。文字も図形も座標で指定して描く。

viewBox ビューボックス

SVG の「用紙サイズ」。この外にはみ出した部分は表示されない。

px（ピクセル） ピクセル

画面上の長さの単位。1px は点1つぶん。今回の「2px のはみ出し」の px。

終了コード しゅうりょうコード

プログラムが返す合否の番号。0 が成功。「0件まで直す」の判定に使える。

Lint リント

書き方の誤りを機械的に見つける仕組み。文書でいう校正ツールにあたる。
