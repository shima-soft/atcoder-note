GLOSSARY

用語解説

このスライドで登場した用語の読み方と概要

Pull Request プルリクエスト

コードの変更をチームに提案する仕組み。「この変更を入れていいか見てください」の申請。

Code Review コードレビュー

他人が書いたコードを確認し、問題や改善点を指摘する作業。品質管理の要。

CLAUDE.md クロード エムディー

プロジェクトのルールを書いたファイル。AIがコードを書くときのガイドラインになる。

GitHub ギットハブ

世界で最も広く使われているコード管理サービス。PRやレビューの履歴もここで管理する。

github.com 🔗
SHA ハッシュ エスエイチエー ハッシュ

コードの変更ごとに自動で振られる一意の識別子。過去の変更を正確に参照するための住所。

偽陽性 ぎようせい

「問題がありそう」と判定されたが、実際には問題ではないもの。ツールの信頼度を下げる要因。

ドラフトPR ドラフト プルリクエスト

まだ完成していない変更の仮レビュー用に作るPR。完成前にレビューされないようにする仕組み。

Dependabot ディペンダボット

GitHubの自動ツール。ライブラリの更新が必要になると自動でPRを作成する。

github.com 🔗
エージェント エージェント

特定のタスクを持つAI。今回のプラグインでは5つのエージェントがそれぞれ得意分野を担当する。
