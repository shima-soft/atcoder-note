一言で

set() で集合を作り、要素数を N と M と比べるだけ。Python なら4行で完結する

abc454_b.py 
# 入力受け取り
N, M = map(int, input().split())
F = list(map(int, input().split()))

# 集合（重複なし）に変換
S = set(F)

# Q1: 全員が異なる服を着ているか？
#     集合の要素数 == 人数 なら重複なし
print("Yes" if len(S) == N else "No")

# Q2: 全種類の服が着られているか？
#     集合の要素数 == 服の種類数 なら全種類登場
print("Yes" if len(S) == M else "No")
📊 計算量
時間: O(N) N 個の要素を1回ずつ集合に追加するだけ
空間: O(N) 最大 N 要素の集合を1つ保持
N ≤ 100 なので最大100回の処理。
ネストしたループ O(N²) と比べると
100×100=10,000 回 → たった100回で済む！
🧪 全サンプル確認
3 4 / 1 2 4 → Yes / No len({1,2,4})=3==3✓ 3≠4✗
4 2 / 1 2 1 2 → No / Yes len({1,2})=2≠4✗ 2==2✓
4 4 / 1 3 2 1 → No / No len({1,2,3})=3≠4✗ 3≠4✗
5 5 / 1 3 4 2 5 → Yes / Yes len({1,2,3,4,5})=5==5✓ 5==5✓
✅ ポイントまとめ
  • set(F) ひとつで Q1・Q2 両方に対応
  • len(S)==N → 単射（全員バラバラ）
  • len(S)==M → 全射（全種類カバー）
