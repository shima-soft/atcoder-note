イベントリストとカウント辞書で効率的に処理

from collections import defaultdict def solve(): # 入力読み込み n, m = map(int, input().split()) # 日ごとのイベントリスト changes = [[] for _ in range(m + 1)] cnt = defaultdict(int) # 色のカウント kind = 0 # 色の種類数 # 各鳥の情報を処理 for _ in range(n): a, d, b = map(int, input().split()) # 初期色のカウント if cnt[a] == 0: kind += 1 cnt[a] += 1 # イベントを記録 if d <= m: changes[d].append((a, b)) # 各日のイベントを処理 for day in range(1, m + 1): for a, b in changes[day]: # 色aのカウントを減らす cnt[a] -= 1 if cnt[a] == 0: kind -= 1 # 色bのカウントを増やす cnt[b] += 1 if cnt[b] == 1: kind += 1 print(kind)
🔍 コードのポイント
1

`changes[d]`: d日目のイベントリスト

2

`cnt[a]`: 色aを持つ鳥の数

3

`kind`: 現在存在する色の種類数

✅ 計算量
  • 初期設定: O(N)
  • イベント処理: 合計O(N)
  • 日ループ: O(M)
  • 合計: O(N+M) ← 30万でも余裕
⚠️ 実装の注意
  • defaultdict を使うと初期値0で便利
  • イベントはd<=mのときだけ記録
