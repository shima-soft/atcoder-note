用語解説

このスライドで登場した用語の読み方と概要

BFS（幅優先探索） ビーエフエス / Breadth-First Search

グラフをノード1に近い順（幅）に探索するアルゴリズム。キューを使って実装する。最短経路や到達可能性の検出に使われる。

有向グラフ ゆうこうグラフ / Directed Graph

辺に「向き」があるグラフ。A→B の辺はあっても B→A はないことがある。本問ではアイテム交換ルールを辺として表現した。

DFS（深さ優先探索） ディーエフエス / Depth-First Search

グラフを「できる限り深く」辿り、行き詰まったら戻るアルゴリズム。スタックまたは再帰で実装。BFS と同様に到達可能性を調べられる。

隣接リスト りんせつリスト / Adjacency List

グラフの辺を「各ノードの隣接ノードリスト」として表現するデータ構造。メモリ効率がよく、BFS・DFS の標準的な実装に使われる。

O記法（計算量） オーきほう / Big-O Notation

処理ステップ数の「おおよその増え方」を表す記法。O(N+M) は「データ数 N と M に比例した時間で終わる」を意味し、実用的に高速と言える。
