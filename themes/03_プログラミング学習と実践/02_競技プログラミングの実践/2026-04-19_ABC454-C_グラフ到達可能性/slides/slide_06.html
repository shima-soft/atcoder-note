まとめ

隣接リスト + BFS で O(N+M)。30万データも一瞬で処理できる

Python abc454_c.py 
from collections import deque

def solve():
    N, M = map(int, input().split())

    # 隣接リスト: graph[A] = [B1, B2, ...]
    graph = [[] for _ in range(N + 1)]
    for _ in range(M):
        a, b = map(int, input().split())
        graph[a].append(b)

    # BFS 開始 (ノード1 から)
    visited = [False] * (N + 1)
    visited[1] = True
    queue = deque([1])
    count = 1          # アイテム1は最初から保持

    while queue:
        v = queue.popleft()
        for u in graph[v]:
            if not visited[u]:
                visited[u] = True
                queue.append(u)
                count += 1

    print(count)

solve()
⏱ 計算量の内訳
① グラフ構築: O(M) — M 本の辺を1回ずつリストへ追加
② BFS 探索: O(N+M) — 各ノード・各辺をそれぞれ最大1回処理
合計 O(N+M) — N=M=30万でも 約60万回の処理のみ ✅
✅ コードの3つのポイント
① 隣接リストで辺を管理 → 各ノードの隣接を O(1) で列挙
② visited 配列で同じノードを2度以上処理しない
③ deque の popleft() で先頭取り出し O(1) を保証
🗺 問題解法まとめ
読替 交換ルール → 有向グラフの辺（A→B）
構築 graph[a].append(b) で隣接リスト作成
探索 ノード1から BFS → 到達ノード数を計上
出力 count（訪問済みノード数）を print
