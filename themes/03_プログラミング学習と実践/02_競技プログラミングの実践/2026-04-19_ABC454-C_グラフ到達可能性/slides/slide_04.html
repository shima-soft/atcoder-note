KEY INSIGHT

グラフに変換すれば解ける！

気づき

「交換ルール」を有向グラフの辺として描くと、到達可能ノード数が答えになる

🔄 問題の読み替え
→ アイテム = グラフのノード（頂点）
→ 「Aを渡すとBがもらえる」= A から B への有向辺
→ 「手に入れられる種類数」= ノード1から到達できるノード数
✅ 正解アルゴリズム

有向グラフを構築し、ノード1からBFS（幅優先探索）を実行。
探索で訪問できたノードの総数が答え！

📊 計算量の見通し
✓ グラフ構築: O(M)（辺を1本ずつ追加）
✓ BFS探索: O(N+M)（各ノード・辺を1回ずつ処理）
✓ N=M=30万でも 約60万回の処理 → 楽々クリア！
💼 仕事に例えると

「資格A→資格B受験可」を組織図に描いたとき、最初の資格1から辿れる資格の総数を求めるのと同じ
