1
半分の位置を出す
N は必ず偶数。後半は N ÷ 2 個で、先頭は N ÷ 2 ＋ 1 番目から始まる。
2
添字に直す
Python の添字は 0 から。「N ÷ 2 ＋ 1 番目」は添字 n // 2 になり、＋1 は消える。
3
最後まで足す
添字 n // 2 から最後まで順に足すだけ。触るのは全体の半分で済む。
