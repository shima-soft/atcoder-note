実装

後半の開始位置を n // 2 で求め、そこから最後まで順に足すだけ

PYTHON
n = int(input())
a = list(map(int, input().split()))

half = n // 2
total = 0
for i in range(half, n):
    total = total + a[i]

print(total)

1〜2行目 — 入力を受け取る

1行目の個数を int(input()) で整数にして n へ。2行目は input().split() で空白ごとに切り分け、 map(int, ...) で全部を整数に変え、list(...) でリスト a にまとめる。

4〜5行目 — 後半の開始位置と合計の箱

n // 2 は割り算の答えを整数で求める書き方。n=8 なら half は 4 になり、これが後半の先頭の添字。 合計を入れる total は 0 から始める。

6〜9行目 — 後半だけを足して出力

range(half, n) は half から n の1つ手前までの番号を順に出す。 n=8 なら 4・5・6・7 の4回まわり、a[i] を total に足していく。最後に total を表示する。

✅ 慣れてきたら
  • a[half:] は「halfから最後まで」の取り出し
  • print(sum(a[half:])) と1行にもできる
