GLOSSARY

用語解説

このスライドで登場した用語の読み方と概要

数列 すうれつ

数を順番に並べたもの。今回の A がこれにあたる。

Wikipedia: 数列 🔗
標準入力 ひょうじゅんにゅうりょく

データがプログラムに届く入り口。AtCoderではここから自動で流れてくる。

Wikipedia: 標準ストリーム 🔗
input() インプット

標準入力から1行ぶんを文字列として読み込む命令。

Python: input 🔗
int() イント

文字列の "8" を数の 8 に変える命令。計算の前に必ず通す。

Python: int 🔗
map() マップ

並んだ要素すべてに同じ変換をかける命令。「全員まとめて整数に」。

Python: map 🔗
list() リスト

値を順番に並べて持つ入れ物。数列 A の置き場になる。

Python: list 🔗
添字 そえじ / インデックス

リストの何番目かを指す番号。Pythonでは 0 から始まる。

Wikipedia: 配列 🔗
整数除算 // せいすうじょざん

小数点以下を切り捨てて割り算する記号。8 // 2 は 4。

Python: 算術演算 🔗
range() レンジ

連続した番号を順に出す命令。range(4, 8) は 4・5・6・7。

Python: range 🔗
スライス スライス

リストの一部を範囲指定で切り出す書き方。a[4:] など。

Python: スライス 🔗
sum() サム

リストの中身をまとめて合計する命令。ループの代わりに使える。

Python: sum 🔗
AtCoder アットコーダー

日本発の競技プログラミングサイト。毎週のABCが入門に最適。
