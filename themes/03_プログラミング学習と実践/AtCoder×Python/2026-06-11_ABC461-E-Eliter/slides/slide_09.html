解法パターンの整理

ポイント

「上書きは最後の時刻だけ持つ」「総数は増減で更新」「時刻の集計は BIT」— 3 点セットで覚えよう

1
後勝ちの整理
行の黒と列の白が重なったら、
後に塗った方が勝つ。

だからマスを覚える必要はなく、
行・列の「最後に塗られた時刻」
（row_time / col_time）だけ持てばよい。
メモリは O(N) で済む。
時刻の比較
2
総数は増減だけ更新
毎回数え直すと O(N) × Q 回で破綻。

行を黒に: +（N − 今の黒マス数）
列を白に: −（今の黒マス数）

変化した 1 行・1 列の差分だけを
合計に反映する。
差分更新
3
時刻の集計は BIT
「時刻◯より前／後に塗られた本数」を
O(log Q) で数える集計表。

足す・引く・累計の 3 操作だけで、
全体 O(Q log Q) ≈ 540 万回。
Q = 3×10⁵ でも Python で間に合う。
BIT（Fenwick Tree）
🔁 今日の解法パターン（上書き系クエリの定石）
グリッドは作らない → 行・列の最後の時刻だけ記録 → 総数は増減だけ更新 → 時刻の集計は BIT → O(Q log Q) で完答
