クエリ処理 — 増減を足し引きして即出力（20 行）

ポイント

「前回時刻 old を調べる → 今の黒マス数を BIT で出す → 時刻を t に引っ越す」が両クエリ共通の型

PYTHON — クエリ処理 + 出力
row_time = [0] * (N + 1)
col_time = [0] * (N + 1)
bit_add(row_bit, 0, N)
bit_add(col_bit, 0, N)
total = 0
for t in range(1, Q + 1):
    typ, x = map(int, input().split())
    if typ == 1:
        old = row_time[x]
        total += N - bit_sum(col_bit, old - 1)
        bit_add(row_bit, old, -1)
        bit_add(row_bit, t, 1)
        row_time[x] = t
    else:
        old = col_time[x]
        total -= N - bit_sum(row_bit, old)
        bit_add(col_bit, old, -1)
        bit_add(col_bit, t, 1)
        col_time[x] = t
    print(total)
🔍 行を黒に塗るとき（typ == 1）
1

今の黒マス数 = bit_sum(col_bit, old - 1)
（時刻 old より前に白塗りされた列の本数）

2

total += N − 黒マス数 で増加分だけ加算

3

時刻の引っ越し: old の件数を −1、t に +1

✅ 列を白に塗るとき（else）
  • 消える黒 = N - bit_sum(row_bit, old) ＝ 時刻 old より後に黒塗りされた行の本数
  • 初期値は「全行・全列が時刻 0」— だから最初に時刻 0 へ N 件ずつ登録
⏱ 計算量
  • 1 クエリ O(log Q) × Q 回 = O(Q log Q) ≈ 540 万回
  • O(N log N) 級は N ≤ 5×10⁵ が目安 → Q = 3×10⁵ なら Python でも間に合う（不安なら PyPy 提出）
