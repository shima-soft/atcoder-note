入力と BIT（時刻カウント表）の準備（20 行）

ポイント

行用と列用、2 本の BIT を用意する。中身は「足す・引く・累計を出す」の 3 機能だけ

PYTHON — 入力 + BIT の道具立て
import sys
input = sys.stdin.readline

N, Q = map(int, input().split())
size = Q + 2
row_bit = [0] * (size + 1)
col_bit = [0] * (size + 1)

def bit_add(bit, i, x):
    i += 1
    while i <= size:
        bit[i] += x
        i += i & (-i)
def bit_sum(bit, i):
    i += 1
    s = 0
    while i > 0:
        s += bit[i]
        i -= i & (-i)
    return s
🔍 それぞれの役割
1

row_bit ＝ 行を黒く塗った時刻の集計表
col_bit ＝ 列を白く塗った時刻の集計表

2

bit_add(表, 時刻, x) … その時刻の件数を x だけ増減

3

bit_sum(表, 時刻) … 時刻 0〜t の累計件数を返す

✅ 実装のコツ
  • 時刻は 0〜Q を使うので、表の長さは Q + 2 で確保
  • 冒頭の i += 1 は「時刻 0」も表で扱うためのずらし（BIT は 1 始まり）
📝 i & (-i) について
  • 2 進数で「担当ブロック」を渡り歩くテクニック。仕組みは後回しでOK、使い方を覚えるのが先
