総数は数え直さない — 増減だけを足し引きする

ポイント

変わるのは「いま塗った 1 行・1 列」だけ。そこで増えた数・減った数だけ合計に反映する

📐 増減の式
黒

行 R を黒に → 行はまるごと黒になる
増加 = N −（直前にその行で黒かった数）

白

列 C を白に → 列はまるごと白になる
減少 =（直前にその列で黒かった数）

✅ 「直前に黒かった数」も時刻で分かる
  • 行 R の黒マス数 = 行 R の時刻より前に白塗りされた列の本数（行の黒が上書きして勝っている分）
  • 列 C の黒マス数 = 列 C の時刻より後に黒塗りされた行の本数（列の白の上に塗られた分）
⚠️ ただし毎回数えたら台無し
  • 全行・全列を見て数えると 1 回 O(N) — 合計 9×10¹⁰ 回で TLE
  • 高速に数える道具が必要 →次のスライドの BIT
