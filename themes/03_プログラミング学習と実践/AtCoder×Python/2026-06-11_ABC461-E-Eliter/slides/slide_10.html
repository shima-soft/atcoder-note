用語解説

このスライドで登場した用語の読み方と概要

BIT（Fenwick Tree） ビット / フェニックツリー

「件数の増減」と「先頭からの累計」をどちらも O(log N) でこなす集計表。売上台帳の小計欄のデータ構造版。本問では行用・列用の 2 本を使った。

Wikipedia: フェニック木 🔗
クエリ query

「この処理をして」という指示・問い合わせの 1 件。本問では「行を黒に」「列を白に」の 2 種類が最大 3×10⁵ 件届く。1 件あたりの処理を速くするのが腕の見せ所。

Wikipedia: クエリ 🔗
O 記法 オーきほう / Big-O notation

アルゴリズムの計算量（実行時間の増え方）を表す記法。本問の解法は O(Q log Q) — クエリ数 Q に対してほぼ比例でしか増えない。

Wikipedia: ランダウの記号 🔗
TLE ティーエルイー / Time Limit Exceeded

実行時間制限超過。本問の制限は 2 秒で、グリッドを素直にシミュレートする解法は確実に TLE になる。制約から「速い解法を要求されている」と読み取る。

AtCoder 公式 🔗
標準入力 ひょうじゅんにゅうりょく

プログラムにデータを渡す基本の入り口。競プロではここから問題の入力が流れてくる。キーボード入力やファイルからの流し込みも同じ仕組み。

Wikipedia: 標準ストリーム 🔗
sys.stdin.readline シス・スタンダードイン・リードライン

Python で標準入力を高速に読む方法。input() より数倍速い。本問のように入力が 3×10⁵ 行を超える問題では必須のテクニック。

Python公式: sys.stdin 🔗
map マップ

リストなどの各要素に同じ関数をまとめて適用する Python の組み込み関数。map(int, input().split()) は「空白区切りの文字列を全部 int に変換」の定型句。

Python公式: map 🔗
AtCoder アットコーダー

日本最大級の競技プログラミングサイト。毎週土曜夜の ABC（Beginner Contest）は初学者の腕試しに最適。E 問題は中級者へのステップアップ問題。
