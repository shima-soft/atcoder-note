一言で

K手以内に「安全な空マス」へ避難できる空マスの個数を数える

問題の概要

縦 H × 横 W のマス目があります。. は普通に入れる空マス、# は入れない爆弾マスです。上下左右の空マスへだけ移動できます。

安全な空マス ＝ 「そのマスの行にも列にも爆弾が1個もない」空マス。

各空マスについて「K回以下の移動で安全な空マスに到達できるか？」を判定し、条件を満たす空マスの個数を出します。

制約（何を意味する？）

  • H, W ≤ 5×105、かつ H×W ≤ 5×105
  • 0 ≤ K ≤ H×W−1
  • → マスの総数は最大50万個。「全マスからしらみつぶしに探索」は無理そう、と読み取る

入力例 1（H=3, W=3, K=1）

#.. ... ..#
#.. .安全. ..#

行1・行3・列1・列3に爆弾があるため、「安全な空マス」は中央の (2,2) だけ。そこへ K=1 回以内で届くのは、(2,2) と上下左右の4マスの 5個 → 出力 5

入力例 2（K=0・爆弾なし）

爆弾がないので全部の空マスが安全。移動 0 回で条件OK → 出力 6。
K=0 でも「そのマス自身が安全なら答えに含む」ことに注意。
