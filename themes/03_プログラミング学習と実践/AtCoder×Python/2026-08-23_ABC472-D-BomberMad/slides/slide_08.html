多始点BFS本体（19行）

実装

安全マスを距離0で全部キューへ。あとは普通の幅優先探索

PYTHON（中盤）
q = deque()
for i in range(H):
    for j in range(W):
        if S[i][j] == '.' and not row[i]:
            if not col[j]:
                dist[i][j] = 0
                q.append((i, j))

while q:
    i, j = q.popleft()
    for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        ni = i + di
        nj = j + dj
        if 0 <= ni < H and 0 <= nj < W:
            if S[ni][nj] == '.':
                if dist[ni][nj] == -1:
                    dist[ni][nj] = dist[i][j] + 1
                    q.append((ni, nj))

1〜8行目 — 出発点を全部キューへ

「空マス ∧ 行にも列にも爆弾なし」＝安全マスを、距離 0 にしてキューに追加する。ここが多始点BFSの心臓部。

9〜11行目 — 先頭を取り出す

while q: でキューが空になるまで回す。i, j = q.popleft() は「座標のペア (i, j) を取り出す」書き方。

12〜19行目 — 4方向へ広げる

上下左右 (di, dj) を試し、グリッド内・空マス・未訪問（dist が −1）の3条件を満たしたら距離＋1で登録。

✅ ポイント
  • 爆弾マスには絶対に距離を書かない（S[ni][nj] == '.' のチェック）
  • dist == -1 の確認で二重登録を防ぐ
