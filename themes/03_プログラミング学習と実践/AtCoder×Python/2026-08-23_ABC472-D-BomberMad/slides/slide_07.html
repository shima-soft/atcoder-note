準備：爆弾のある行・列（20行）

実装

row[ ]・col[ ] を先に作り、距離表 dist を −1 で初期化する

PYTHON（前半）
import sys
input = sys.stdin.readline
from collections import deque

H, W, K = map(int, input().split())
S = []
for _ in range(H):
    S.append(input())

row = [False] * H
col = [False] * W
for i in range(H):
    for j in range(W):
        if S[i][j] == '#':
            row[i] = True
            col[j] = True

dist = []
for _ in range(H):
    dist.append([-1] * W)

1〜3行目 — 準備

input = sys.stdin.readline は大量入力を速くする定番のおまじない。H は最大50万行になることもあるため入れておく。

10〜16行目 — 爆弾のある行・列を記録

全マスを見て、# ならその行と列に印をつける。row[i] ＝「行 i に爆弾があるか」、col[j] ＝「列 j に爆弾があるか」。

18〜20行目 — 距離表の初期化

dist[i][j] に「最寄り安全マスまでの距離」を書き込んでいく。−1 は「まだ調べていない」の意味。

✅ 前計算のおかげで
  • 「(i,j) は安全か？」が次スライドで not row[i] and not col[j] の1発判定になる
