K以内のマスを数えて完成（7行）

実装

dist が 0〜K の空マスを数えるだけ。全体 O(HW) で余裕

PYTHON（後半）
ans = 0
for i in range(H):
    for j in range(W):
        if S[i][j] == '.':
            if dist[i][j] != -1 and dist[i][j] <= K:
                ans += 1
print(ans)

全体の計算量

O(HW)

前計算 O(HW) ＋ BFS O(HW) ＋ 集計 O(HW)。
H×W ≤ 5×105。O(N) 型は Python でも N ≤ 107 程度までOKなので、余裕を持って間に合う。

3〜6行目 — 条件を満たすマスを数える

全マスをもう一周し、空マスかつ距離が 0〜K（安全マス自身の距離0も含む）ならカウント。

K=0 のときは？

条件は「dist = 0」＝そのマス自身が安全。入力例2のように、爆弾がなければ全マスが答えになる。

⚠️ やりがちなバグ
  • dist[i][j] != -1 を忘れると危険
  • どこからも届かない空マスは −1 のまま。−1 ≤ K は真なので誤って数えてしまう
✅ 安全マスが1個もない入力
  • BFSが1回も走らず ans = 0 のまま。特別扱いは不要
