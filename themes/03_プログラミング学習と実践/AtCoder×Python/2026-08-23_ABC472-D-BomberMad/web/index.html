ABC472 D / 400点 / 茶色 ★★☆

Bomber Mad

爆弾グリッドで、K手以内に「安全な空マス」へ避難できる空マスの個数を数える。多始点BFS（始点を全部キューへ）で O(HW) に落とします。

1

行・列を前計算

安全な空マスが一瞬で判定できる

2

逆から考える

全マス個別探索は約2,500億ステップで不可

3

多始点BFS

全マスの最寄り距離を一括計算

問題を読み解く

縦 H × 横 W のマス目があります。. は空マス、# は爆弾マス。上下左右の空マスへだけ移動できます。

安全な空マス ＝ そのマスの行にも列にも爆弾が1個もない空マス。各空マスが K 回以下の移動で安全な空マスへ到達できるかを判定し、条件を満たす空マスの個数を出力します。

制約が示すこと

H×W ≤ 5×105（最大50万マス）、0 ≤ K ≤ H×W−1。この規模感が「全マスからしらみつぶし探索は無理」の合図です。

入力例1（H=W=3, K=1）

#.. ... ..#

行1・行3・列1・列3に爆弾があるため、安全な空マスは中央 (2,2) のみ。K=1 で届くのは自分を含む 5個。

セルフチェック：「隣に爆弾がない空マス」は安全な空マス？

いいえ。同じ行・列のどこか遠くに爆弾があっても安全ではありません。行と列全体を見ます。

セルフチェック：K=0 のとき数えられるのは？

そのマス自身が安全な空マスなら、移動0回で条件OK。自分自身も答えに含めます。

「安全な空マス」を見分ける

地雷原の区画が完全に安全と言えるのは、縦・横どちらの通り道にも地雷が1個もないとき。グリッドではマス単体ではなく、行と列の状態に注目します。

前計算

各行に爆弾があるか row[i]、各列にあるか col[j] を全マス一周で記録。「(i,j) は安全か？」は not row[i] and not col[j] の1発判定になります。

よくある誤解

「隣に爆弾がないマス」のことではない。同じ行・列のどこか遠くに爆弾があっても安全ではありません。

セルフチェック：安全判定に必要な情報は？

row[i] と col[j] の2つだけ。前計算しておけば個々のマスを行や列ごと舐め直す必要がありません。

全マスから調べるのは間に合わない

直球アプローチ

各空マスから個別にBFS。空マス 最大50万 × 探索1回 最大50万歩 ＝ 最悪 約2,500億ステップ。制限時間2秒では絶対に終わりません。

発想の転換

知りたいのは「最寄りの安全マスまでの距離」。向きが逆でも本質は同じ。安全マス側から同時に塗り広げれば探索は1回で済みます。

セルフチェック：PythonでO(N²)が耐えられる目安は？

N ≤ 3,000 程度。今回は N（マス数）≤ 50万なので桁違いにアウトです。

安全マス側から一気に広げる

倉庫（安全マス）全部から同時にトラックを出発させ、各地点に「最初に届いた便の所要時間」を書き込む作業です。これが多始点BFS。普通のBFSとの違いは初期化だけで、「距離0のマスをキューに全部入れてから始める」だけです。

  • なぜ正しいか: BFSは近い場所から順に訪れるので、各マスに最初に書き込まれた数＝最寄り安全マスまでの距離になる。
  • 実務での対応: 避難所の到達圏の計算、通信インフラのカバー範囲の推定など「複数拠点からの最寄り距離」を知りたい場面にそのまま使えます。
セルフチェック：普通のBFSからの変更点は？

初期化だけです。始点1個の代わりに全始点をキューに入れてからループを始めます。道具は deque 1本。

サンプル1で動きを追う

1

安全な空マスに「0」と書く

2

隣の空マスへ「＋1」と書いていく

3

距離が K 以下の空マスを数える

⚠️ 移動ルールに注意

爆弾マスは通れないため、距離の書き込みは空マスだけです。

AC想定コード

公式サンプル3件・コーナーケース（安全マスなし／K=0）・最大サイズ50万マスの動作を確認済みのコードです。スライドのコード①〜③をつなげたものが丸ごと1ファイルになります。

abc472d.py ✅ 公式サンプル確認済み 
import sys
input = sys.stdin.readline
from collections import deque

H, W, K = map(int, input().split())
S = []
for _ in range(H):
    S.append(input())

row = [False] * H
col = [False] * W
for i in range(H):
    for j in range(W):
        if S[i][j] == '#':
            row[i] = True
            col[j] = True

dist = []
for _ in range(H):
    dist.append([-1] * W)

q = deque()
for i in range(H):
    for j in range(W):
        if S[i][j] == '.' and not row[i]:
            if not col[j]:
                dist[i][j] = 0
                q.append((i, j))

while q:
    i, j = q.popleft()
    for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        ni = i + di
        nj = j + dj
        if 0 <= ni < H and 0 <= nj < W:
            if S[ni][nj] == '.':
                if dist[ni][nj] == -1:
                    dist[ni][nj] = dist[i][j] + 1
                    q.append((ni, nj))

ans = 0
for i in range(H):
    for j in range(W):
        if S[i][j] == '.':
            if dist[i][j] != -1 and dist[i][j] <= K:
                ans += 1
print(ans)
セルフチェック：dist[ni][nj] != -1 の確認を忘れると？

同じマスが何度も登録されて処理が膨張します。未訪問（−1）の確認で二重登録を防いでいます。

セルフチェック：集計で dist[i][j] != -1 を忘れると？

どこからも届かない空マスは −1 のままですが「−1 ≤ K」は真なので誤って数えてしまいます。

計算量

項目規模
前計算（row / col / dist 初期化）O(HW)
多始点BFSO(HW)
集計O(HW)
全体O(HW)

H×W ≤ 5×105。O(N) 型は Python でも N ≤ 107 程度までOKなので余裕を持って間に合います。約2,500億 → 約50万 への削減がすべてです。

まとめ

1

行・列の爆弾有無を前計算して安全マスを特定

2

全マス個別探索は不可 → 安全マス側から考える

3

多始点BFSで全マスの最寄り距離を一括計算

「複数の起点から最寄り距離を知りたい」ときは、起点側から同時に広げる発想を思い出してください。配送圏・到達圏・カバー範囲など、仕事の集計にも応用できる型です。
