問題文・制約・入出力例

一言で

2つの整数に対し、複数のクエリで状態を更新していく問題

問題の概要

2つの整数 $A$ と $B$ が与えられます。 その後、クエリが $Q$ 個与えられ、各クエリによって $A$ または $B$ のビットの状態が更新されます。 最後に $A$ と $B$ の値を求めてください。

制約

- A, B <= 10^9 (約 30ビット) - Q <= 10^5 (10万回)

※ Q が多いため、各クエリで重い計算をすると間に合いません。

入出力例

入力例 1:

A = 3 (0011), B = 5 (0101)
Q = 1, Query = (Update A bit 1)
A = 2 (0010), B = 5 (0101)
