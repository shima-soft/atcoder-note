実装と計算量の確認

一言で

ビットを配列で管理し、クエリごとに $O(1)$ で更新する

# 各ビットの状態を配列で管理
bits_A = [int((A >> i) & 1) for i in range(30)]
bits_B = [int((B >> i) & 1) for i in range(30)]

# クエリ処理
for _ in range(Q):
    t, idx = map(int, input().split())
    if t == 1:
        bits_A[idx] = 1 - bits_A[idx]
    else:
        bits_B[idx] = 1 - bits_B[idx]

# 結果の合成
ans_A = 0
for i in range(30):
    ans_A |= (bits_A[i] << i)

ans_B = 0
for i in range(30):
    ans_B |= (bits_B[i] << i)

print(ans_A)
print(ans_B)

📊 計算量の確認

クエリ数 Q に対して、各クエリを O(1) で処理します。

✅ Pythonでの実行上限
  • 全体計算量: O(Q)
  • Pythonの目安: 10^7（1000万）程度
  • 本問題 (Q=10^5): 余裕を持って間に合います
