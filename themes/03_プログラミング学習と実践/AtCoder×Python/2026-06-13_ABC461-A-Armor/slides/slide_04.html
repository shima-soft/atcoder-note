実装

if と <=（以下）だけで解ける — 考え方をそのままコードに

PYTHON
A, D = map(int, input().split())
if A <= D:
    print("Yes")
else:
    print("No")

1行目 — 入力の受け取り

input().split() で1行を空白で分割し、 map(int, ...) でそれぞれを整数に変換。 A・D に代入する。

2行目 — 条件チェック

A <= D は「AはD以下か？」という意味。 結果が True なら print("Yes")、 False なら print("No") に進む。

3〜5行目 — 結果の出力

条件成立で "Yes"、 不成立で "No" を出力する。

✅ キーワード確認
  • <= → 「以下」(less than or equal)
  • if / else → 条件分岐の基本形
