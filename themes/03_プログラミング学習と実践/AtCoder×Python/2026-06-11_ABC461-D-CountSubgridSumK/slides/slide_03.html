解法ステップ 1

上下を固定して 1 次元の問題に落とす

アイデア

「どの行範囲 × どの列範囲」→ まず行範囲を固定する

Step 1
上辺 u と下辺 d を固定
長方形の行範囲 (u〜d) を全探索する。
組み合わせ数は O(H²) ≈ 125,250 通り（H=500）。
行範囲を固定（青枠）
1 0 0 1
1 1 0 1
0 1 1 0
💡 上辺 u=2, 下辺 d=2（1行のみ）の例。
この範囲の列ごとの和 = [1, 1, 0, 1]
Step 2
列方向の累積和 B を計算
固定した行範囲について、列 j の和を A[j] とする。
B[j] = A[0] + A[1] + ... + A[j-1]（B[0]=0）
A（列ごとの和）
1 1 0 1
→
B（累積和）
0 1 2 2 3
💡 B[r] − B[l] = 列 l+1 〜 r の総和。
→ 1次元配列上の「総和 K の区間」を数える問題に！
Step 3
問題の変換
元の問題は次のように言い換えられる：
各 (u,d) について：
B[r] − B[l] = K となる
(l, r) の組の個数を数えよ
ただし 0 ≤ l < r ≤ W
✓ A[j] ≥ 0 なので B は単調非減少
→ 尺取り法（2ポインタ）が使える！
