解法ステップ 2

尺取り法（2ポインタ）で総和 K の区間を数える

仕組み

B が単調非減少 → (l, r) を前方向にしか進めない

アルゴリズム
count_eq(B, K) — 2ポインタで O(W)
r₁ = 「B[r] − B[l] ≥ K」となる最小の r
r₂ = 「B[r] − B[l] > K」となる最小の r
→ r₂ − r₁ が l 固定時の条件を満たす r の個数
def count_eq(arr, k):
  n = len(arr)
  r1 = r2 = 0
  res = 0
  for l in range(n - 1):
    r1 = max(r1, l + 1)
    r2 = max(r2, l + 1)
    while r1 < n and arr[r1] - arr[l] < k:
      r1 += 1
    while r2 < n and arr[r2] - arr[l] <= k:
      r2 += 1
    res += r2 - r1
  return res
💡 arr = B, k = K で呼ぶと B[r]−B[l]=K のペア数が求まる。
「≥K」と「>K」の差分で「=K」を得る。
動作イメージ
B = [0, 1, 2, 2, 3], K = 1 の場合
B
0 1 2 2 3
r₁
0 1 2 2 3
B[r]−B[l] ≥ 1
r₂
0 1 2 2 3
B[r]−B[l] > 1（≥ 2）
l=0 のとき: r₁=1, r₂=2 → 1個 (r=1) ✅
l が 1 増えると r₁, r₂ も右に進むだけで戻らない。
各ポインタは合計でたかだか W 回しか進まない → O(W)。
💡 全要素が非負という性質が鍵。
負の値があると単調性が崩れ 2ポインタは使えない。
