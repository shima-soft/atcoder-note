このスライドで登場した用語の読み方と概要

尺取り法 しゃくとりほう

2つのポインタ（添え字）を条件に応じて前進させながら範囲を走査するアルゴリズム。しゃくとり虫のようにポインタが動くことから命名。単調性のある配列に対して有効。

詳しくは 🔗
累積和（Prefix Sum） るいせきわ

配列の先頭から i 番目までの総和を事前計算しておくテクニック。区間の総和を O(1) で求められる。B[r]−B[l] で区間 [l+1, r] の和。

詳しくは 🔗
2次元累積和 にじげんるいせきわ

2次元配列の各セルについて、左上からの矩形和を事前計算する手法。長方形領域の和を O(1) で求められる。本問でも列ごとの和を高速に計算するために内部的に使用。

詳しくは 🔗
単調非減少 たんちょうひげんしょう

数列の各要素が前の要素以上である性質（広義の増加）。A[j] ≥ 0 なら累積和 B は単調非減少になる。尺取り法が使える条件。

2ポインタ にポインタ

2つのインデックス（ポインタ）を使って配列を走査する手法。尺取り法の別名。各ポインタが高々1回ずつ配列をなめるため O(N) で動作する。

O(H²W) オー・エイチにじょう・ダブリュー

本解法の時間計算量。H が500、W が500 のとき約1.25×10⁸ 回の操作。競プロでは「500³ までは Python で通ることがある」とされるが、定数倍に注意が必要。

AtCoder アットコーダー

日本発の競技プログラミングプラットフォーム。毎週土曜 21:00 から ABC（AtCoder Beginner Contest）が開催。初心者からトッププロまで幅広く参加。

atcoder.jp 🔗
グリッド（格子） グリッド（こうし）

行と列からなる2次元のマス目構造。競プロでは文字列の配列として与えられることが多い。本問では H×W の各セルが 0 または 1。
