ポイント

1行ごとのprintは呼び出し回数が多いと遅い。文字列を貯めて最後に1回で出力する

PYTHON — DFS本体 + 出力
A = [0] * N
out = []

def dfs(idx, rem):
    if idx == N:
        A[idx - 1] = rem // idx
        out.append(' '.join(map(str, A)))
        return
    for v in range(rem // idx + 1):
        r = rem - idx * v
        if reach[idx + 1][r]:
            A[idx - 1] = v
            dfs(idx + 1, r)

dfs(1, K)
print('\n'.join(out))
🔍 dfs(idx, rem) の流れ
1

idx==N（最後の位置）なら rem÷idx で確定値を代入し、1行分の文字列をoutに追加

2

そうでなければ v を 0 から順に試す（小さい方から試すので辞書順のまま）

3

reach[idx+1][r] が○のときだけ次の位置へ進む（枝刈り）

✅ なぜ1行ずつprintしないのか
  • 出力は最大3×10⁵行。print()を毎回呼ぶと1回ごとの処理コストが積み重なり遅くなる
  • 文字列をリストoutに貯めて'\n'.join(out)で1回にまとめて出力すると大幅に速くなる
