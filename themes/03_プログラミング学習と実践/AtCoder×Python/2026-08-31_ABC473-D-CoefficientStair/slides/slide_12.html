用語解説

このスライドで登場した用語の読み方と概要

深さ優先探索 ふかさゆうせんたんさく / DFS

1つの枝を行き止まりまで先に進めてから次の枝に戻る探索方法。本問では「位置ごとに値を決める」処理をこの順番で行う。

Wikipedia: 深さ優先探索 🔗
動的計画法 どうてきけいかくほう / DP

同じ計算を繰り返さないよう、途中結果を表に記録しながら解く手法。本問では reach[idx][rem] の表がこれにあたる。

Wikipedia: 動的計画法 🔗
枝刈り えだきり / pruning

探索の途中で「この先は答えにならない」と分かった枝を、最後まで進めずに切り捨てる工夫。無駄な計算を大幅に減らせる。

Wikipedia: バックトラック 🔗
辞書式順序 じしょしきじゅんじょ / lexicographic order

辞書の単語の並び方のように、先頭の要素から順に比較して大小を決める順序。数列を先頭から比較して小さい方を先に出力する。

Wikipedia: 辞書式順序 🔗
sys.stdin.readline シス・スタンダードイン・リードライン

Python で高速に標準入力を読み込む方法。input()より速く、出力行数が多い本問のような問題で有効。

Python公式: sys.stdin 🔗
str.join() ストリング・ジョイン

リストの要素を指定した区切り文字でつなげて1つの文字列にするメソッド。大量の行を1回でまとめて出力するのに使う。

Python公式: str.join 🔗
