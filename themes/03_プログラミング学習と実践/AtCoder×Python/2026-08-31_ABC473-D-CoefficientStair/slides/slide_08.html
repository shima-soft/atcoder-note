入力処理 + reach表の構築（12行）

ポイント

reach[idx+1] をコピーしてから伝播させるだけで、「作れるか」の表が埋まる

PYTHON — 入力 + reach表構築
import sys
input = sys.stdin.readline

N, K = map(int, input().split())

reach = [[False] * (K + 1) for _ in range(N + 2)]
reach[N + 1][0] = True
for idx in range(N, 0, -1):
    reach[idx] = reach[idx + 1][:]
    for r in range(idx, K + 1):
        if reach[idx][r - idx]:
            reach[idx][r] = True
🔍 コードの流れ
1

reach[N+1][0]=True（何も使わずrem=0だけ作れる、が出発点）

2

reach[idx] は1つ大きい reach[idx+1] をコピーして作る

3

remをidxから順に増やし、reach[idx][r-idx]が○ならreach[idx][r]も○にする

✅ Python の実行可能上限の目安
  • 全体の計算量は O(N × K)
  • N≤10, K≤2×10⁵ → 最大でも約2×10⁶回のループ
  • O(N)の目安（N≤10⁷）にも収まる規模で、Pythonでも十分間に合う
