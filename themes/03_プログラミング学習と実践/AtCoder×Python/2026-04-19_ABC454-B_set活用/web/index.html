AtCoder ABC454 B

B問題「Mapping」

2つの Yes/No 質問に答えるだけ — Python の set() を使えば4行で解決

Q1: 全員バラバラ？

N人全員が異なる服を着ているか。重複があれば No。

Q2: 全種類カバー？

M種類の服が全て誰かに着られているか。1種類でも欠けたら No。

問題を読み解く

N人とM種類の服

N人の人がいて、それぞれが服番号 F_i（1〜Mの整数）を着ています。上の2つの質問にそれぞれ Yes/No で答えます。

制約

  • 1 ≤ N ≤ 100（人数）
  • 1 ≤ M ≤ 100（服の種類数）
  • 1 ≤ F_i ≤ M（各自が着ている服の番号）

N と M は独立。N が M より大きければ必ずどこかに重複があります（鳩の巣原理）。

入出力例

例NMFQ1Q2
1341 2 4YesNo
2421 2 1 2NoYes
3441 3 2 1NoNo
4551 3 4 2 5YesYes

例1: 全員違う服だが服3を誰も着ていない。例4: 全員違う服＋5種類すべてカバー。

理解度チェック
例3: N=4, M=4, F=[1,3,2,1] で Q1・Q2 が両方 No になる理由は？
Q1: 人1と人4が同じ服1を着ているので重複あり → No
Q2: 服4を誰も着ていないので全カバーできていない → No
どちらの条件も満たせていません。
N=M のとき、Q1=Yes かつ Q2=Yes は同時に成り立ちますか？
成り立ちます。N=M のとき「重複なし」と「全カバー」は同値です。
ただし N≠M の場合はどちらか一方しか Yes にならないか、両方 No になります。
考え方

2つの質問、それぞれ何を確認する？

💼 仕事で例えると…

Q1: 5人の営業担当が「全員バラバラのお客様を担当しているか？」— 同じ顧客を2人で担当していたら重複あり。

Q2: 全部門に最低1人のスタッフがいるか？— 誰も担当していない部署があればカバー不足。

Q1の言い換え

「全員バラバラ」＝ リストに重複がない
重複があれば set() 後に個数が減る。

Q2の言い換え

「全種類カバー」＝ 1〜Mの全番号が最低1回登場
抜けがあれば set() 後の個数が M より少なくなる。

理解度チェック
F=[2,2,2] N=3, M=3 のとき Q1・Q2 はそれぞれ何？
set(F)={2} → len=1
Q1: 1==3 → No（全員同じ服）
Q2: 1==3 → No（服1と3を誰も着ていない）
解法

Pythonの set() で一発解決

Python の set() は「集合型」です。リストを set() に入れると、重複した値が自動で除去されます。

set() の動作例

[1, 2, 1, 2] → set() → {1, 2}
len({1, 2}) = 2

Q1の判定式

len(set(F)) == N
重複なし → set後もN個残る → True → Yes

Q2の判定式

len(set(F)) == M
全カバー → set後ちょうどM種類 → True → Yes

理解度チェック
N=3, M=3, F=[1,1,1] のとき len(set(F)) はいくつ？
set([1,1,1]) = {1} → len=1
Q1: 1==3 → No（重複あり）
Q2: 1==3 → No（服2,3を誰も着ていない）
Pythonコード

完成コード — わずか4行

abc454_b.py ✅ AC 確認済み 
N, M = map(int, input().split())
F = list(map(int, input().split()))

# Q1: 全員バラバラな服？
if len(set(F)) == N:
    print("Yes")
else:
    print("No")

# Q2: 全種類カバーしてる？
if len(set(F)) == M:
    print("Yes")
else:
    print("No")

コード解説

  • 1行目: N（人数）と M（服の種類数）を読み込む
  • 2行目: N人分の服番号リスト F を読み込む
  • 4〜8行目: Q1判定 — len(set(F))==N なら重複なし → Yes、そうでなければ No
  • 10〜14行目: Q2判定 — len(set(F))==M なら全カバー → Yes、そうでなければ No

set() セット Python公式 🔗

Pythonの組み込み型。重複した値を自動で除去した集合を作る。set([1,2,1])→{1,2}。

len() レン / レングス

要素数を返すPython組み込み関数。len({1,2,3})→3。set()と組み合わせてよく使う。

map() マップ

各要素に関数を適用するPython組み込み関数。入力の整数変換によく使う。

🐍 Python 豆知識 競プロで有利な理由

set()・len()・sorted() がそのまま使える。コードが短くなるぶん「解法の考え方」に集中できるのが競プロで Python を使う最大のメリット。
