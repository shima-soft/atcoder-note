このスライドで登場した用語の読み方と概要

AtCoder アットコーダー atcoder.jp 🔗

日本発のプログラミングコンテストプラットフォーム。定期的に開催されるABCなどのコンテストで力試しができる。

ABC エービーシー

AtCoder Beginner Contest の略。毎週土曜開催で、A〜H問題（難易度順）から構成される初心者〜上級者向けコンテスト。

set() セット Python公式 🔗

Pythonの組み込み型。リストから重複を除いた「集合」を作る。set([1,2,1]) → {1,2}。要素の順序は保証されない。

len() レン / レングス

Pythonの組み込み関数。リスト・集合・文字列などの要素数を返す。len({1,2,3}) → 3。

map() マップ

各要素に関数を適用するPython組み込み関数。map(int, "1 2 3".split()) で文字列を整数リストに変換するのが典型的な使い方。

🐍 Python 豆知識 競プロで有利な理由

set()・len()・sorted() がそのまま使える。コードが短くなるぶん「解法の考え方」に集中できるのが競プロで Python を使う最大のメリット。
