解法

Pythonの set() で一発解決

コツ

重複を消してカウントするだけ — Q1は「N個残るか」、Q2は「M個残るか」

🔑 set() とは何か？
1

Pythonの集合型。重複した値を自動で除去する

2

リストを set() に入れると ユニークな値だけが残る

3

len() で個数を数えて N や M と比較するだけ

✅ Q1の判定ロジック
  • 重複なし → set後も N 個残る
  • len(set(F)) == N → Yes
  • 重複あり → set後は N 個より少ない
✅ Q2の判定ロジック
  • 全種類カバー → set後ちょうど M 種類
  • len(set(F)) == M → Yes
  • カバー不足 → set後は M 個より少ない
