問題を読み解く

N人とM種類の服

ポイント

「全員バラバラ？」と「全種類ある？」の2つにそれぞれYes/Noで答える

問題文（噛み砕き版）
N人が服を着ている
N人の人がいて、それぞれ1〜Mのどれかの服を着ています。
以下の2つの質問に Yes か No で答えてください。
1 N人全員がバラバラの服を着ていますか？
（同じ服を2人以上が着ていたらNo）
2 M種類全種類の服を、誰かが着ていますか？
（1種類でも誰も着ていなければNo）
制約
変数の意味と範囲
N 人数（1 ≤ N ≤ 100）
M 服の種類数（1 ≤ M ≤ 100）
F_i i番目の人が着ている服（1 ≤ F_i ≤ M）
関係 N と M は独立。N＞M なら必ず重複あり
入出力例
サンプルで確認
例NMFQ1Q2
1341 2 4 YesNo
2421 2 1 2 NoYes
3441 3 2 1 NoNo
4551 3 4 2 5 YesYes
