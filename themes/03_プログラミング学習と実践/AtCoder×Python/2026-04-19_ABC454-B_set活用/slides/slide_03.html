考え方

2つの質問、それぞれ何を確認する？

気づき

「違う」＝重複なし、「全種類」＝抜けなし —— この2つは別の条件

💼 仕事で例えると…
Q1

5人の社員が「別々の担当顧客を持っているか？」
1人の顧客を2人で担当していたら「重複あり」

Q2

全部門に最低1人のスタッフがいるか？
1つでも空き部門があれば「カバー不足」

✅ Q1が Yes になる条件
  • リスト内に同じ値が1つもない
  • 要素数そのまま = 重複除去後も同じ個数
  • 例: [1,2,4] → 3人3種類 → Yes
✅ Q2が Yes になる条件
  • 1〜Mの全番号が最低1回は登場する
  • ユニーク種類数 = M（抜けがない）
  • 例: [1,2,1,2] M=2 → {1,2}=2種類 → Yes
⚠️ 混同しやすい落とし穴
  • Q1とQ2を同じ条件と勘違い → 独立して判断する
  • N=M でも両方 Yes とは限らない
