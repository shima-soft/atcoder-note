用語解説

このスライドで登場した用語の読み方と概要

絶対値 ぜったいち

数からマイナス符号を取り除いた値。−2 も 2 も絶対値は 2。「どれだけ離れているか」を表すのに使う。

Wikipedia: 絶対値 🔗
abs() アブス

絶対値を返す Python の組み込み関数。abs(x - i) で左右どちらの離れ方も同じ形で測れる。

Python ドキュメント: abs 🔗
文字列 もじれつ

文字を並べたデータ。今回の S のように S[i] で1文字ずつ取り出して調べられる。

Python ドキュメント: 文字列 🔗
インデックス いんでっくす

「何番目か」を表す番号。Python は 0 から数えるので、マス1 は S[0] にあたる。

Wikipedia: 添字 🔗
全探索 ぜんたんさく

考えられる場合を1つずつすべて調べる方法。今回はマスとガードマンの組み合わせを総当たりで確認する。

二重ループ にじゅうるーぷ

for の中にもう1つ for を書く形。「全マス × 全ガードマン」のような組み合わせを調べるときの定番。

フラグ ふらぐ

「見つかったかどうか」を覚えておく目印の変数。True / False の2択で持つ。今回の watched がこれ。

Python ドキュメント: 真偽値 🔗
input() インプット

1行分の入力を文字列として読み込む組み込み関数。AtCoder では毎回使う基本の命令。

Python ドキュメント: input 🔗
map() マップ

並んだ要素すべてに同じ変換をかける関数。map(int, ...) は「全部まとめて整数に直す」定型文。

Python ドキュメント: map 🔗
