実装

「マスごとに全ガードマンを確認する」を、そのまま二重ループに書く

PYTHON
M, D = map(int, input().split())
S = input()

count = 0
for x in range(M):
    watched = False
    for i in range(M):
        if S[i] == "G" and abs(x - i) <= D:
            watched = True
    if watched == False:
        count += 1

print(count)

1〜2行目 — 入力の受け取り

1行目でマスの数 M と距離 D を整数として読み込み、 2行目で配置の文字列 S を受け取る。 S[i] で i 番目の1文字を取り出せる。

5〜6行目 — 調べたいマスを1つ選ぶ

Python は 0 から数えるので x = 0 がマス1。 watched（見られているか）を False にしておく — これが「フラグ」の役割をする。

7〜9行目 — 全ガードマンとの距離を確認

S[i] == "G" でガードマンを見つけ、 abs(x - i) <= D なら見張られている。番号を0から数えても 差は変わらないのでそのまま使える。1人でも見つかれば True にする。

10〜13行目 — 残ったマスを数える

最後まで False のままだったマスだけ count を1増やし、 全部調べ終えたら出力する。
