📝 問題を読み解く

1列に並んだ M個のマス（廊下）があり、G のマスにはガードマンが立っています。ガードマンは自分から距離D以内のマスを見張ります。最後まで誰にも見張られなかったマスが何個あるかを答えてください。

答えるのは「見張られた数」ではなく「見張られなかった数」です。ここを取り違えると、正しく数えても不正解になります。

🔒 制約

  • 0 ≤ D < M ≤ 100
  • S は G と . だけの長さ M の文字列

→ マスは最大100個。全部のマスを1つずつ調べても余裕

→ D が 0 になる場合もあることに注意

📥 入力形式

M D
S

1行目にマスの数と見張れる距離、2行目に配置の文字列。出力は「見張られていないマスの個数」を1行だけ。

📊 入出力例

M DS（配置）出力なぜそうなる？
7 1.G...GG1見張られないのはマス4だけ
6 5......6ガードマンが0人。全マスが見張られない
21 2....G...GG.....G.....6両端と真ん中の空白地帯、合わせて6マスが残る

💡 考え方 — 見張れるのは「左右にDマスずつ」

ガードマンは左だけ、あるいは右だけを見ているわけではありません。左右どちらにも D マスずつ目が届きます。

距離の測り方はマス番号の引き算です。ただしそのまま引くとマイナスになることがあるため、絶対値を取ります。Python なら abs() で一発です。

店舗を巡回する担当者の受け持ち範囲と同じ

①

担当者がいる店から、左右にD店ずつが受け持ち範囲

②

距離は「番号の差」— 左右どちらでも測り方は同じ

③

誰の受け持ちにもならない店が、今回の答え

✅ 距離の測り方

  • マス4とマス2の距離 → 4 − 2 = 2
  • マス2とマス4の距離 → 2 − 4 = −2 の絶対値で 2

❌ ありがちな勘違い

  • 右側だけ見張ると思ってしまう（左右どちらも見張る）
  • D = 0 のとき何も見張らないと思ってしまう
🤔 理解度セルフチェック（クリックで答えを表示）
  1. D = 0 のガードマンは何マスを見張りますか？ 答え: 自分が立っている1マスだけです。距離0以内には自分自身が含まれます。
  2. マス3のガードマン（D = 2）はどこまで見張れますか？ 答え: マス1からマス5までです（左に2マス、右に2マス）。

⚠️ つまずきポイント — 見張り範囲の「足し算」では数えられない

「ガードマン1人につき見張れるマス数を計算して全部足す」——この方法はうまくいきません。入力例1で試すと、3 + 3 + 2 で 8マス。廊下は7マスしかないのに、見張られたマスが8個になってしまいます。

原因は重なりです。マス6とマス7は、マス6の人からもマス7の人からも見張られているため、二重にカウントされています。

そこで視点をひっくり返します。ガードマン側から数えるのをやめて、マス側から「自分は誰かに見られているか」を1回だけ確認するのです。

①

担当者ごとの受け持ち店数を足すと、重複分が二重に乗る

②

店側から「誰か担当がいるか」を1回だけ確認する

③

この見方なら、重なっていても数え間違えない

✅ マスごとに見るメリット

  • 範囲が重なっても1回しか数えない
  • 端からはみ出した分も自然に無視できる

❌ 足し算方式のつまずき

  • 重なりを引く計算が必要になり複雑化する
  • 端で範囲が切れる分も別途調整が必要
🤔 理解度セルフチェック（クリックで答えを表示）
  1. 2人のガードマンから同時に見張られているマスは、何マスとして数えますか？ 答え: 1マスです。塗り絵と同じで、同じ場所を2回塗っても面積は増えません。
  2. マス側から確認すると、なぜ端の処理が楽になるのですか？ 答え: 存在しないマスは、そもそもマス側から見にいかないためです。

✍️ 手を動かす — 入力例1の7マスを塗りつぶしてみる

M は 7、D は 1、配置は「.G...GG」。ガードマンはマス2・マス6・マス7の3人です。3人分の見張り範囲を重ねて塗り、残ったマスを数えます。

①

ガードマンごとに見張り範囲を書き出す

②

すべての範囲を重ねて、廊下を塗りつぶす

③

塗られずに残ったマスの数が答え

マス1〜3はマス2の人が、マス5〜7はマス6の人が、マス6〜7はマス7の人が塗ります。マス7の人の右側（マス8）は存在しないので無視します。残ったのはマス4だけ——答えは 1 です。

✅ 他の入力例でも同じ手順

  • 「......」D=5 → ガードマンが0人なので6マス
  • 「....G...GG.....G.....」D=2 → 残るのは6マス

❌ ここで間違えやすい

  • マス7の範囲は右にはみ出すが、存在しない分は無視
  • 「監視された数」ではなく「されていない数」を答える

💻 コード — Python 13行で完成

外側のループが「調べるマス」、内側のループが「ガードマン探し」。塗り絵の手順が、そのまま二重ループになります。

abc468_b.py ✅ AC 確認済み 
M, D = map(int, input().split())
S = input()

count = 0
for x in range(M):
    watched = False
    for i in range(M):
        if S[i] == "G" and abs(x - i) <= D:
            watched = True
    if watched == False:
        count += 1

print(count)

行ごとの解説

1〜2行目 — 入力の受け取り: マスの数 M と距離 D を整数として読み込み、配置の文字列 S を受け取る。S[i] で i 番目の1文字を取り出せる。

5〜6行目 — 調べたいマスを1つ選ぶ: Python は 0 から数えるので x = 0 がマス1。watched（見られているか）を False にしておく — これが「フラグ」の役割をする。

7〜9行目 — 全ガードマンとの距離を確認: S[i] == "G" でガードマンを見つけ、abs(x - i) <= D なら見張られている。番号を0から数えても差は変わらないのでそのまま使える。1人でも見つかれば True にする。

10〜13行目 — 残ったマスを数える: 最後まで False のままだったマスだけ count を1増やし、全部調べ終えたら出力する。

✅ ここだけ押さえる

  • 1人でも見つかれば True。何人いても数え方は変わらない
  • abs() で左右の距離を同じ形で判定できる

❌ 書き間違えやすい所

  • watched を外側のループの外で初期化してしまう
  • 不等号を < にして D ちょうどのマスを外してしまう
🤔 理解度セルフチェック（クリックで答えを表示）
  1. watched = False を外側のループの外に書くと、どうなりますか？ 答え: 一度 True になると戻らないため、以降のマスがすべて「見張られている」判定になります。
  2. abs() を使わずに x - i <= D と書くと、どうなりますか？ 答え: 差がマイナスのときも条件が成立してしまい、左側に遠く離れたマスまで見張られる判定になります。
