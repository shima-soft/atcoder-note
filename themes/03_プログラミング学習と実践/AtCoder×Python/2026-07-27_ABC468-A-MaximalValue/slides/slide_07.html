GLOSSARY

用語解説

このスライドで登場した用語の読み方と概要

数列 すうれつ

数を順番に並べたもの。売上表を日付順に並べたイメージで、順番そのものに意味がある。

Wikipedia: 数列 🔗
リスト りすと

Python で複数の値を順番に持つ入れ物。A[0] のように 0 番から取り出す。

Python ドキュメント: リスト 🔗
全探索 ぜんたんさく

考えられる場所を1つずつすべて調べる方法。今回は3つ組を端から端まで確認するだけで足りる。

標準入力 ひょうじゅんにゅうりょく

プログラムにデータを流し込む仕組み。AtCoder ではテストケースがここから自動で渡される。

Wikipedia: 標準ストリーム 🔗
input() インプット

標準入力から1行を文字列として読み込む組み込み関数。AtCoder では毎回使う。

Python ドキュメント: input 🔗
split() スプリット

文字列を空白で切り分けてリストにするメソッド。「3 1 4」→「3」「1」「4」に分ける。

Python ドキュメント: str.split 🔗
map() マップ

並んだ要素すべてに同じ変換をかける関数。map(int, ...) は「全部まとめて整数に直す」。

Python ドキュメント: map 🔗
range() レンジ

0 から指定した数の「手前まで」の連番を作る関数。range(4) は 0,1,2,3 の4回分。

Python ドキュメント: range 🔗
and アンド

2つの条件が「両方とも成り立つ」ときだけ真になる書き方。片方でも崩れると偽。

Python ドキュメント: ブール演算 🔗
AtCoder アットコーダー

日本発の競技プログラミングサイト。毎週コンテストが開催され、初心者向けの ABC が入門に最適。

atcoder.jp 🔗
