実装

「窓を1つずつずらして山を数える」をそのまま for ループに書く

PYTHON
N = int(input())
A = list(map(int, input().split()))

count = 0
for i in range(N - 2):
    if A[i] < A[i + 1] and A[i + 1] > A[i + 2]:
        count += 1

print(count)

1〜2行目 — 入力の受け取り

1行目で個数 N を整数として読み込む。2行目の list(map(int, input().split())) は 「空白区切りの数字をまとめて整数に直し、リストにする」定型文。

4〜5行目 — 窓を1つずつずらす

count は山の個数を入れる箱。 range(N - 2) でちょうど N-2 回だけ繰り返し、 3つ組をすべて調べる。

6〜9行目 — 山なら1つ足して出力

左隣より大きく、右隣より大きいときだけ count += 1。最後に count を出力する。

✅ ここだけ押さえる
  • リストの番号は 0 から始まる（先頭は A[0]）
  • and は「両方成り立つ」ときだけ真
