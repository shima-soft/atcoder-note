入力と右端ソート（11行）

まず、1回だけ必要な前処理を済ませる

import sys

input = sys.stdin.readline
N, K = map(int, input().split())

cloths = []
for _ in range(N):
    L, R = map(int, input().split())
    cloths.append((L, R))

cloths.sort(key=lambda cloth: cloth[1])
読みどころ
1

N枚の [L, R] をタプルで保存

2

key で2要素目の R を指定

3

右端の昇順が貪欲法の土台

ここは O(N log N)
  • ソートは二分探索の外で1回だけ
  • 判定のたびに並べ替えない
