二分探索 + 貪欲判定（16行）

mid を固定するたび、右端順に1回走査する

ok = 0
ng = 10**9 + 1

while ng - ok > 1:
    mid = (ok + ng) // 2
    selected_count = 0
    last_right = -10**18

    for left, right in cloths:
        if left - last_right >= mid:
            selected_count += 1
            last_right = right

    if selected_count >= K:
        ok = mid
    else:
        ng = mid
核心はこの2変数
K

必要な布の枚数

last_right

最後に選んだ布の右端

布を選ぶ条件と更新
  • 前の布との距離 left - last_right が、候補の距離 mid 以上なら選ぶ
  • 選んだ布の右端を保存：last_right = right
最初の1枚
  • last_right を十分小さくし、必ず選べるようにする
