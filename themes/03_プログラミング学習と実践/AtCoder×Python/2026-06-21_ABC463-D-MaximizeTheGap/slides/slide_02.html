ABC463 D — Maximize the Gap

📝 何を求める問題？

数直線上に N 枚の布があり、布 i は閉区間 [Li, Ri] を覆います。互いに重ならない K 枚を選び、布どうしの距離の最小値をできるだけ大きくしてください。K 枚選べなければ -1 です。

🔒 制約

  • 2 ≤ K ≤ N ≤ 2×105（20万）
  • 0 ≤ Li < Ri ≤ 109

→ 全組合せは不可。座標幅には二分探索が効く

⚠️ 閉区間の注意

[1,5] と [5,9] は点5を共有するため重なります。整数座標では、重ならない隣同士の距離は必ず1以上です。

📊 サンプル1 — 2・4・6枚目を選ぶとスコア2

1: [1,12]
2: [2,7]
3: [5,9]
4: [9,13]
5: [10,18]
6: [15,20]
171320

[2,7]→[9,13] の距離は2、[9,13]→[15,20] も2。最小は 2。距離3以上で3枚は選べません。
