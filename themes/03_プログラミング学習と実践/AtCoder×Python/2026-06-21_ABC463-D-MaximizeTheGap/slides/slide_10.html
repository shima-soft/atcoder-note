コード③ / 計算量

0なら -1、それ以外は最大距離

if ok == 0:
    print(-1)
else:
    print(ok)
なぜ 0 → -1？
  • 整数座標で重ならない布の距離は1以上
  • 距離1すらK枚選べなければ、条件を満たす選択が存在しない

全体の計算量

右端ソートO(N log N)
1回の判定O(N)
判定回数約30回
O(N log N + N log M)

M ≤ 109。実質は「ソート + 約30回の線形走査」です。O(N log N) / O(N log M) は Python で N ≤ 5×105 程度が目安。この問題の N ≤ 2×105 なら範囲内です。
