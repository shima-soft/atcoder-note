問題を読み解く

N枚の布 i が閉区間 [Li, Ri] を覆います。互いに重ならないK枚を選び、布どうしの距離の最小値を最大にします。K枚選べなければ -1。

制約が示すこと

N ≤ 2×105 なので全組合せは不可。座標 ≤ 109 は答えの二分探索に向きます。

閉区間に注意

[1,5] と [5,9] は点5を共有するため重なります。重ならない整数区間の距離は1以上です。

セルフチェック：サンプル1のスコアが2になる理由は？

[2,7]・[9,13]・[15,20]を選ぶと、隣の距離が2と2で、その最小値が2だからです。

「距離x以上で選べるか？」へ変換

次の L − 前の R ≥ x

xで可能なら、それより小さい値も可能です。xで不可能なら、それより大きい値も不可能。判定結果には単調性があり、二分探索できます。

OK側

x = 1, 2, …

NG側

… x = 3, 4（サンプル1）

右端が早い布から選ぶ

布をRの昇順に並べます。条件を満たす布を見つけたら選び、最後の右端を更新します。早く終わる布ほど右側に広い空きを残すので、後の候補を減らしません。

  1. Rの昇順にソート
  2. L - last_right >= x なら選ぶ
  3. K枚以上選べたらxは実現可能
セルフチェック：左端順ではなく右端順なのはなぜ？

右端が早い布を選ぶと、次に使える空間を最大にできるからです。

最大のOKを二分探索

ok = 0

可能側の番兵。最後まで0なら答えは存在しません。

ng = 109 + 1

必ず不可能な側。

mid = (ok + ng) // 2 を判定し、可能ならok、不可能ならngをmidへ動かします。差が1で終了します。

提出コード

公式サンプル3件（2 / -1 / 35）で確認済みです。

abc463d.py✅ AC想定・公式サンプル確認済み
import sys

input = sys.stdin.readline
N, K = map(int, input().split())

cloths = []
for _ in range(N):
    L, R = map(int, input().split())
    cloths.append((L, R))

cloths.sort(key=lambda cloth: cloth[1])

ok = 0
ng = 10**9 + 1

while ng - ok > 1:
    mid = (ok + ng) // 2
    selected_count = 0
    last_right = -10**18

    for left, right in cloths:
        if left - last_right >= mid:
            selected_count += 1
            last_right = right

    if selected_count >= K:
        ok = mid
    else:
        ng = mid

if ok == 0:
    print(-1)
else:
    print(ok)

計算量

処理計算量
右端ソートO(N log N)
貪欲判定O(N)
二分探索O(log M)、約30回
全体O(N log N + N log M)

M ≤ 109。N ≤ 2×105 はPythonでも現実的な範囲です。
