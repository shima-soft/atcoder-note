このスライドで登場した用語の読み方と概要

標準入力 ひょうじゅんにゅうりょく

キーボードからプログラムにデータを送る仕組み。AtCoderの問題では、テストケースがここから自動で流し込まれる。

Wikipedia: 標準ストリーム 🔗
input() インプット

標準入力から1行を文字列として読み込む Python の組み込み関数。AtCoderでは毎回使う基本の命令。

Python ドキュメント: input 🔗
map() マップ

リストの各要素に同じ変換を適用する関数。「全員を一括で整数に変換」するイメージ。map(int, ...) はよく使う定型文。

Python ドキュメント: map 🔗
int() イント

文字列 "16" を整数 16 に変換する関数。input() が返すのは文字列なので、計算前に必ず変換が必要。

Python ドキュメント: int 🔗
剰余演算子 % じょうよえんざんし

割り算の余りを求める記号。a % b == 0 は「aがbで割り切れる」という判定によく使う。

Python ドキュメント: 算術演算 🔗
整数除算 // せいすうじょざん

割り算の商を、小数点以下を切り捨てた整数で求める記号。9 // 2 は 4 になる。

Python ドキュメント: 算術演算 🔗
条件分岐 じょうけんぶんき

条件（True/False）に応じて処理を切り替える仕組み。Pythonでは if / else で書く。日常でいう「もし〜なら〜、そうでなければ〜」。

AtCoder アットコーダー

日本発の競技プログラミングプラットフォーム。世界中のプログラマーが参加するコンテストを毎週開催。初心者向けの ABC が入門に最適。
