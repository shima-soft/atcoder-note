実装

4つの式をif文で順番にチェックし、1つでも一致したら nine を True にする

PYTHON
a, b = map(int, input().split())
nine = False
if a + b == 9:
    nine = True
if a - b == 9:
    nine = True
if a * b == 9:
    nine = True
if a % b == 0 and a // b == 9:
    nine = True
if nine:
    print("Nine")
else:
    print("Nein")

1〜2行目 — 入力の受け取りと下準備

input().split() で1行を空白で分割し、map(int, ...) で整数に変換して a・b に代入。 「一致したか」を覚えておく箱として nine = False を先に用意する。

3〜10行目 — 4つの式を順番にチェック

足し算・引き算・掛け算・割り算を1つずつ if で確認し、9と一致したら nine = True に書き換える。 割り算だけは a % b == 0（割り切れる）かつ a // b == 9（商が9）で判定し、小数のズレを避ける。

11〜14行目 — 結果の出力

nine が True のままなら "Nine"、一度も一致しなければ "Nein" を出力する。

✅ キーワード確認
  • % → 「余り」(割った余り)
  • // → 「商」(小数点以下を切り捨てる割り算)
