用語解説

このスライドで登場した用語の読み方と概要

AtCoder アットコーダー

日本発の競技プログラミングプラットフォーム。問題を解いてコードを提出すると正解かどうかを自動判定してくれる。ABC（Beginner Contest）は毎週土曜夜に開催。

→ atcoder.jp
閉区間 へいくかん

両端の値を含む整数の範囲のこと。[3, 5] なら 3, 4, 5 の 3 つすべてが含まれる。「以上・以下」がどちらも含む（対義語は「開区間」= 端を含まない）。

→ Wikipedia: 区間（数学）
標準入力 ひょうじゅんにゅうりょく

プログラムが外部から受け取るデータの経路。AtCoder では問題の入力が標準入力で渡され、Python では input() で受け取る。

→ Wikipedia: 標準ストリーム
map 関数 マップかんすう

リストや入力の各要素に同じ処理を一括で適用する Python の組み込み関数。map(int, "3 5".split()) で文字列の「3」「5」を整数に変換できる。

→ Python 公式ドキュメント
