気づき②

答えは「k個目のはずれの位置」

計算量

O(N) — Python では N ≤ 1000万 が目安。80万なら余裕で間に合う

💡 解き方の手順（3ステップ）
①

S を左から1回なめ、x の位置を順にメモ

②

k 番目のメモがあれば、それが答え

③

メモが k 個に足りなければ答えは N

✅ 計算量まとめ
  • x の位置を集める: O(N)
  • 各 k は取り出すだけ: 合計 O(N)
  • Python で O(N) は N ≤ 1000万 が目安
⚠️ 実装の注意
  • 位置は1から数える（添字は0からなので +1）
  • N行を1行ずつ print すると遅い → まとめて出力
