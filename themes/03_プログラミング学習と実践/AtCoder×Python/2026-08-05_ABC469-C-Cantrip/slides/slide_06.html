実装

x の位置を1回集めるだけ — ループは2本、どちらも N 回で終わる

PYTHON
import sys

data = sys.stdin.read().split()
N = int(data[0])
S = data[1]

xpos = []
for i in range(N):
    if S[i] == 'x':
        xpos.append(i + 1)

ans = []
for k in range(1, N + 1):
    if k <= len(xpos):
        ans.append(xpos[k - 1])
    else:
        ans.append(N)

print('\n'.join(map(str, ans)))

1〜5行目 — 入力の受け取り

sys.stdin.read() で入力を丸ごと読み、空白で分割。 data[0] が N、data[1] が文字列 S。

7〜10行目 — はずれの位置を集める

左から順に見て、x だったら「何番目か」を xpos に追加。 添字は0から始まるので i + 1 にする。

12〜17行目 — 各 k の答えを作る

k 個目のはずれがあれば xpos[k - 1]、 足りなければ最後まで食べられるので N。

19行目 — まとめて出力

N 行を改行でつないで1回で出力する。 1行ずつ print すると80万回かかって遅い。

✅ キーワード確認
  • sys.stdin.read() → 入力を一気に読む
  • map(str, ans) → 各要素を文字列に変換
  • '\n'.join() → 改行でつないで1つの文字列に
