ABC469 C — Cantrip

📝 何を求める問題？

お菓子が1個ずつ入った袋が N個 一列に並んでいます。 i番目の袋は文字列 S の i文字目が o なら「当たり」、x なら「はずれ」。

まず先頭から k個の袋を受け取り、中のお菓子を食べます（袋は手元に残る）。 そのあとは「手元に当たりの袋がある」かつ「列に袋が残っている」間、 当たりの袋を1枚捨てて、列の先頭の袋を1個受け取り、お菓子を食べます。

k = 1, 2, …, N のそれぞれについて、食べられるお菓子の個数を答えてください。

🔒 制約（入力の範囲）

  • 1 ≤ N ≤ 8×10^5（80万）
  • S は o と x だけの長さ N の文字列

→ 答えを N 個も出す。1つの k を1回のシミュレーションで解くと間に合わない

📥 入力と出力の形式

N袋の個数
S当たり・はずれの並び（例: oxoxo）

出力は N 行。l 行目に k=l のときの答えを書く

📊 入力例1で確認（N=5, S=oxoxo → 出力 2, 4, 5, 5, 5）

k 出力 なぜそうなる？（左から o x o x o）
1 2 1個目 o で当たり1枚 → 捨てて2個目 x を開けると当たり0枚 → 終了
2 4 o x で当たり1枚 → 3個目 o は当たりなので枚数キープ → 4個目 x で0枚 → 終了
3 5 o x o で当たり2枚 → 4個目 x で1枚、5個目 o で1枚のまま → 列が空になって終了
4, 5 5 最初から4個以上もらうので、当たりが尽きるより先に列が空になる
入力例2ooo → はずれが1つも無いので、どの k でも N=3 個すべて食べられる
入力例3x → 1個目がはずれ。k=1 で1個食べた時点で当たりが0枚 → 答えは 1
