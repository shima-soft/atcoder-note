シミュレーション シミュレーション

問題文の手順をそのままプログラムで再現する解き方。確実だが、回数が多いと時間が足りなくなる。

TLE ティーエルイー

Time Limit Exceeded の略。実行時間の制限を超えて不正解になること。今回の制限は2秒。

問題ページ（実行時間制限） 🔗
計算量 けいさんりょう

N が増えたとき処理回数がどう増えるかの目安。O(N) は N に比例。Python では 1000万回あたりが2秒の目安。

不変量 ふへんりょう

操作を繰り返しても崩れない関係式。今回の「手持ちの当たり = k − 引いたはずれの数」がそれにあたる。

Wikipedia: ループ不変条件 🔗
添字 そえじ

文字列やリストの「何番目か」を表す番号。Python は0から数えるので、人が数える位置にするには +1 する。

Python ドキュメント: 文字列 🔗
sys.stdin.read システムスタンダードインリード

標準入力をまとめて1回で読み込む関数。input() を何十万回も呼ぶより圧倒的に速い。

Python ドキュメント: sys.stdin 🔗
str.join ストリング ジョイン

リストの中身を区切り文字でつないで1つの文字列にする。大量の行を一度に出力するときの定番。

Python ドキュメント: str.join 🔗
