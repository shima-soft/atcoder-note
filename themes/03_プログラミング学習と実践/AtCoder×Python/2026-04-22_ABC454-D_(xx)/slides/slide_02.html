括弧の付け外しで文字列を変形できるか？

ポイント

隣り合う2つの x を囲む括弧だけ付け外しできる。AをBに変形できるか判定する

問題文（噛み砕き版）
操作可能な2種類の変換
文字列 A と B が与えられる。
使える文字は (・x・) の3種類だけ。
1 (xx) → xx 括弧を外す
2 xx → (xx) 括弧を付ける
操作は何度でも・どの順でも使える。
A を B に変形できる？ → Yes / No で答える
制約
変数の意味と範囲
T テストケース数（≤ 3×10⁵）
|A|, |B| 各文字列の長さ（≥ 1）
Σ(|A|+|B|) 全ての文字列長の合計（≤ 2×10⁶）
使える文字 (・x・) のみ
💡 合計文字数 ≤ 200万。
1文字あたり O(1) の処理が必要。
入出力例（抜粋）
サンプルで確認
(xx)x → x(xx) Yes
(x)x → (xx) No
)x()x( → )x()x( Yes
x → (x) No
例1: (xx)x → xxx → x(xx)
例2: x の間に ) があるので操作できない
