このスライドで登場した用語の読み方と概要

スタック stack

後から入れたものを最初に取り出すデータ構造（LIFO）。Python のリストで append/pop を使って実現する。皿を積み上げるイメージ。

Wikipedia: スタック 🔗
正規形 せいきけい / canonical form

変換操作を繰り返してたどり着く「これ以上変えられない標準の形」。同じ正規形を持つ文字列どうしは互いに変換可能。

LIFO ライフォ

Last In, First Out（後入れ先出し）の略。スタックの動作原則で、最後に追加した要素を最初に取り出す。

Wikipedia: スタック 🔗
不変量 ふへんりょう / invariant

操作を何回行っても変わらない性質のこと。「不変量が同じ = 変換可能」という考え方は競プロで頻出。

Wikipedia: 不変量 🔗
list.append() アペンド

Python リストの末尾に要素を追加するメソッド。スタックへの「積む（push）」操作に使う。計算量 O(1)。

Python公式ドキュメント 🔗
list.pop() ポップ

Python リストの末尾から要素を取り出すメソッド。スタックからの「取り出す（pop）」操作に使う。計算量 O(1)。

Python公式ドキュメント 🔗
テストケース test case

問題の入力と期待される出力の組。競プロでは T 個のテストケースをまとめて処理することが多い。

str.rstrip() アールストリップ

文字列末尾の空白・改行を取り除くメソッド。sys.stdin.readline は行末の \n を含むため必須。
