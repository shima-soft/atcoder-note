メイン処理 + 計算量まとめ

ポイント

A と B の正規形をそれぞれ求めて比較するだけ。全体の計算量は O(文字列合計長)

PYTHON — メイン処理
T = int(input())
for _ in range(T):
    A = input().rstrip()
    B = input().rstrip()
    if canonical(A) == canonical(B):
        print("Yes")
    else:
        print("No")
canonical の計算量
O(n)
n = 文字列の長さ
全体の計算量
O(Σ|A|+|B|)
≤ 2×10⁶ → 余裕
Python 実行目安
N ≤ 10⁷
O(n) は Python で十分高速
リスト比較
O(n)
== でリスト全体を比較
✅ 解法の全体像（3ステップ）
  • ① A の正規形（canonical）をスタックで計算：O(|A|)
  • ② B の正規形（canonical）をスタックで計算：O(|B|)
  • ③ 2つの正規形を比較：O(|A| or |B|)
  • → 合計 O(|A|+|B|) × T = O(全文字数) ≤ O(2×10⁶)
💡 input().rstrip() が必要な理由
  • 行末の改行文字 \n を取り除くため
  • sys.stdin.readline は改行を含んで読み込む
