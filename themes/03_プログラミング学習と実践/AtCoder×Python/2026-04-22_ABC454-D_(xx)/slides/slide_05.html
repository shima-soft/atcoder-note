アルゴリズム

スタックで正規形を1回のスキャンで求める

ポイント

文字を1つずつ積んでいき、) を見たときトップ3が (・x・x なら括弧を取り除く

📚 スタックの3ルール
1

) 以外の文字はそのままスタックに積む

2

) を読んだとき、スタックのトップ3が
(・x・x なら → 3つ取り出して x・x を積む

3

トップ3がそれ以外なら → ) をそのまま積む

✅ なぜ1パスで十分？
  • スタックに積む際、既に処理済みの文字が積まれている
  • 内側の (xx) を消すと、外側の (xx) がトップに現れる
  • → 自然に内側から順番に処理できる
✅ 計算量
  • 各文字は最大1回 push、1回 pop → O(n)
  • N ≤ 10⁷ なら Python でも間に合う
  • 全テストケース合計 ≤ 2×10⁶ → 十分高速
