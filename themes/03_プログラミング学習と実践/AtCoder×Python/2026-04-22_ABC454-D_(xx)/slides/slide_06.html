正規形を計算する関数 canonical(s)（17行）

ポイント

スタックを使い、) を見るたびにトップ3を確認。(xx) なら3つ取り出して x,x を積む

PYTHON — canonical 関数
import sys
input = sys.stdin.readline

def canonical(s):
    stack = []
    for c in s:
        if c != ')':
            stack.append(c)
        elif (len(stack) >= 3 and
              stack[-1] == 'x' and
              stack[-2] == 'x' and
              stack[-3] == '('):
            stack.pop()   # x を取り出す
            stack.pop()   # x を取り出す
            stack.pop()   # ( を取り出す
            stack.append('x')  # x,x はそのまま残す
            stack.append('x')
        else:
            stack.append(')')
    return stack
🔍 処理の流れ
1

) 以外の文字（( や x）は
そのままスタックに追加

2

) を見たとき、スタックの末尾3つが
(・x・x かチェック

3

一致 → 3つ取り出して x,x を積む
不一致 → ) をそのまま積む

✅ stack[-3], [-2], [-1] の意味
  • stack[-1]：一番上（最後に積んだ要素）
  • stack[-2]：上から2番目
  • stack[-3]：上から3番目
  • Python のリストはマイナス添字で末尾から参照できる
✅ 戻り値はリスト
  • 文字列ではなくリストを返している
  • 次のスライドで == 比較するだけなので十分
