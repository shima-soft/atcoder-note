アルゴリズム

Xでソート → 最小Yを追跡

計算量

O(N log N) — Python で N ≤ 50万 なら間に合う

💡 アルゴリズムの流れ（3ステップ）
①

全ポイントを X座標の昇順にソートする

②

左から順に処理し、minY（最小Y）を追跡する

③

各点の Y ≤ minY ならカウントし、minY を更新

✅ 計算量まとめ
  • ソート: O(N log N)
  • 走査: O(N)
  • 合計: O(N log N)
  • Python で N ≤ 50万 なら間に合う
⚠️ 注意点
  • X座標はすべて異なる（順列なので）
  • minY の更新は判定後に行う
