実装

ソートしてから1回の走査で判定 — シンプルな貪欲法

PYTHON
import sys

N = int(sys.stdin.readline())
points = []
for _ in range(N):
    x, y = map(int, sys.stdin.readline().split())
    points.append((x, y))

points.sort()

ans = 0
minY = float('inf')
for x, y in points:
    if y <= minY:
        ans += 1
    minY = min(minY, y)

print(ans)

1〜6行目 — 入力の受け取り

sys.stdin.readline() で高速に入力読み込み。 N個のポイントを (x, y) のタプルとしてリストに格納する。

8行目 — X座標でソート

points.sort() でX座標の昇順にソート。 タプルのsortは最初の要素（X）で比較される。

10〜14行目 — 最小Yを追跡しながら走査

minY は「今まで見た点の最小Y」。 現在の y ≤ minY なら、左側に自分よりYが小さい点は存在しない → カウント。

15行目 — 結果の出力

条件を満たす点の数 ans を出力する。

✅ キーワード確認
  • .sort() → リストをソート（デフォルトは昇順）
  • float('inf') → 無限大（初期値として使用）
