GLOSSARY

用語解説

このスライドで登場した用語の読み方と概要

順列 じゅんれつ

1〜N の数字を1つずつ並べたもの。重複なく全ての数字が1回ずつ使われる。

Wikipedia: 順列 🔗
ソート ソート

データを並べ替えること。Python の .sort() はデフォルトで昇順（小さい順）に並べる。

Python ドキュメント: list.sort 🔗
貪欲法 たんよくほう

各ステップで「今この瞬間最善」な選択をするアルゴリズム。全体最適を保証しない場合もあるが、この問題では使える。

計算量 けいさんりょう

アルゴリズムの処理時間を表す指標。O(N log N) は「N×log N のオーダー」で、N=50万程度まで Python で間に合う。

sys.stdin.readline システムスタンダードインリードライン

標準入力から1行高速に読み込む関数。input() よりも速いため、AtCoder では入力が多い問題でよく使う。

Python ドキュメント: sys.stdin 🔗
float('inf') フロート インフィニティ

「無限大」を表す値。最小値の初期値として使い、最初の点は必ず条件を満たすようにする。

Python ドキュメント: float 🔗
Pareto最適 パレトさいてき

「他のどの選択肢よりも1つ以上が良く、残りが同等以上」の状態。この問題の正解点はPareto最適点に相当する。

Wikipedia: パレート最適 🔗
AtCoder アットコーダー

日本発の競技プログラミングプラットフォーム。毎週コンテストが開催されていて、初心者向けの ABC が入門に最適。
