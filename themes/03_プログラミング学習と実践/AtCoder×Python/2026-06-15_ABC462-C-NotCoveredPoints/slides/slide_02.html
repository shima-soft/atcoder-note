ABC462 C — Not Covered Points

📝 何を求める問題？

2次元平面上に N個の点があります。 各点 i の座標は (X_i, Y_i)。 左下が (0,0)、右上が (X_i, Y_i) の長方形の内部に どの点も含まれない i の個数を求めてください。

🔒 制約（入力の範囲）

  • 1 ≤ N ≤ 3×10^5（30万）
  • X, Y はそれぞれ 1〜N の順列

→ N が大きいので O(N²) は TLE。O(N log N) が必要

📥 入力の形式

N

1行目にN、以下N行に各点の座標

X_1 Y_1

📊 入出力例で確認（サンプル1: N=3）

点 座標 出力 なぜそうなる？
i=1 (2, 1) OK 長方形(0,0)→(2,1) の内部に他の点なし
i=2 (1, 3) OK 長方形(0,0)→(1,3) の内部に他の点なし
i=3 (3, 2) NG 長方形(0,0)→(3,2) の内部に点1(2,1)が含まれる

→ 答えは 2（i=1, 2 の2つ）
