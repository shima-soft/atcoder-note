ABC462 C — Not Covered Points

長方形の内部に点がない条件を、ソートと最小値追跡で効率的に判定

← 一覧へ戻る 問題ページ 🔗 スライドモードで見る 🔗

📝 問題を読み解く

2次元平面上に N個の点があります。各点 i の座標は (X_i, Y_i)。左下が (0,0)、右上が (X_i, Y_i) の長方形の内部に、どの点も含まれない i の個数を求めてください。

🔒 制約

  • 1 ≤ N ≤ 3×10^5（30万）
  • X, Y はそれぞれ 1〜N の順列

📥 入力形式

N

1行目にN、以下N行に各点の座標

📊 入出力例（サンプル1: N=3）

点座標結果理由
i=1(2, 1)OK長方形(0,0)→(2,1) の内部に他の点なし
i=2(1, 3)OK長方形(0,0)→(1,3) の内部に他の点なし
i=3(3, 2)NG長方形(0,0)→(3,2) の内部に点1(2,1)が含まれる

→ 答えは 2（i=1, 2 の2つ）

💡 考え方

「長方形の内部に点がない」は、「その点の左下に点がない」と読み替えられます。

①

全ポイントを X座標の昇順にソートする

②

左から順に処理し、minY（最小Y）を追跡する

③

各点の Y ≤ minY なら「左側に小さい点なし」→ カウント+1

📊 トレース（サンプル1）

順番点minY（前）Y ≤ minY?結果
1(1, 3)∞3 ≤ ∞ ✓カウント+1
2(2, 1)31 ≤ 3 ✓カウント+1
3(3, 2)12 ≤ 1 ✗スキップ

💻 コード（Python）

abc462c.py ✅ AC 確認済み 
import sys

N = int(sys.stdin.readline())
points = []
for _ in range(N):
    x, y = map(int, sys.stdin.readline().split())
    points.append((x, y))

points.sort()

ans = 0
minY = float('inf')
for x, y in points:
    if y <= minY:
        ans += 1
    minY = min(minY, y)

print(ans)

解説

1〜6行目: sys.stdin.readline() で高速に入力読み込み。N個のポイントをタプルとしてリストに格納。

8行目: points.sort() でX座標の昇順にソート。

10〜14行目: minY を追跡しながら走査。Y ≤ minY ならカウントし、minY を更新。

15行目: 結果を出力。

計算量

ソート O(N log N) + 走査 O(N) = O(N log N)。Python で N ≤ 50万 なら時間内に通ります。
