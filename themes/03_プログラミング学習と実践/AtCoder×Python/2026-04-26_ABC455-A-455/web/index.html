ABC455 A — 455

📝 何を求める問題？

整数 A・B・C が与えられます。 「A と B が異なる」かつ「B と C が等しい」の 両方が成り立つとき "Yes"、そうでなければ "No" を出力してください。

🔒 制約

  • 1 ≤ A, B, C ≤ 9
  • A・B・C はすべて整数

1〜9の1桁の整数しか来ない

📥 入力の形式

A B C

1行に空白区切りで与えられる

例: 4 5 5 → A=4, B=5, C=5

📊 入出力例

入力 出力 なぜそうなる？
4 5 5 Yes A=4 ≠ B=5 ✓ かつ B=5 = C=5 ✓ → 両方OK
1 3 7 No B=3 ≠ C=7 → 条件②が成立しない
6 6 6 No A=6 = B=6 → 条件①が成立しない
考え方

2つの条件を順番に確認する

「かつ」は両方OKで初めてYes — どちらか1つでも×ならNo

✅ Yesになる条件
  • A ≠ B（AとBが違う）
  • B = C（BとCが同じ）
  • 上記の両方が同時に成立しているとき
❌ Noになる例
  • 1 3 7 → B=3 ≠ C=7 なので条件②がNG
  • 6 6 6 → A=6 = B=6 なので条件①がNG
コード

Python 5行で完成

考え方がそのままコードに変わる — if と and だけで解ける

abc455_a.py ✅ AC 確認済み 
A, B, C = map(int, input().split())
if A != B and B == C:
    print("Yes")
else:
    print("No")

1行目 — 入力の受け取り

input().split() で1行を空白で分割し、map(int, ...) でそれぞれを整数に変換。A・B・C に代入する。AtCoder でほぼ毎回使う定型文。

2行目 — 条件チェック（かつ）

A != B は「AとBが違うか？」、B == C は「BとCが等しいか？」を確認。and で「両方OKか？」を一度に判定する。

3〜5行目 — 結果の出力

条件が成立していれば "Yes"、どちらかが成立しなければ "No" を出力する。

✅ キーワード確認
  • != → 「等しくない」(not equal)
  • == → 「等しい」(equal equal、代入の = と混同注意)
  • and → 「かつ」(両方が True のとき True)

用語解説

このスライドで登場した用語の読み方と概要

標準入力 ひょうじゅんにゅうりょく

キーボードからプログラムにデータを送る仕組み。AtCoderの問題では、テストケースがここから自動で流し込まれる。

Wikipedia: 標準ストリーム 🔗
input() インプット

標準入力から1行を文字列として読み込む Python の組み込み関数。AtCoderでは毎回使う基本の命令。

Python ドキュメント: input 🔗
map() マップ

リストの各要素に同じ変換を適用する関数。「全員を一括で整数に変換」するイメージ。map(int, ...) はよく使う定型文。

Python ドキュメント: map 🔗
int() イント

文字列 "5" を整数 5 に変換する関数。input() が返すのは文字列なので、計算前に必ず変換が必要。

Python ドキュメント: int 🔗
条件分岐 じょうけんぶんき

条件（True/False）に応じて処理を切り替える仕組み。Pythonでは if / else で書く。日常でいう「もし〜なら〜、そうでなければ〜」。
