実装

考え方がそのままコードに変わる — if と and だけで解ける

PYTHON
A, B, C = map(int, input().split())
if A != B and B == C:
    print("Yes")
else:
    print("No")

1行目 — 入力の受け取り

input().split() で1行を空白で分割し、 map(int, ...) でそれぞれを整数に変換。 A・B・C に代入する。

2行目 — 条件チェック（かつ）

A != B は「AとBが違うか？」、 B == C は「BとCが等しいか？」を確認。 and で「両方OKか？」を一度に判定する。

3〜5行目 — 結果の出力

条件が成立していれば "Yes"、 どちらかが成立しなければ "No" を出力する。

✅ キーワード確認
  • != → 「等しくない」(not equal)
  • == → 「等しい」(equal equal)
  • and → 「かつ」(両方成立)
