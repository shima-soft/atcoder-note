入力処理と累積和の計算（11行）

解説

各シーケンスのサイズを計算し、累積和の配列を構築

N, K = map(int, input().split())

L = []
A = []
C = []

for i in range(N):
    line = list(map(int, input().split()))
    L.append(len(line) - 1)
    A.append(line[:-1])
    C.append(line[-1])

cumsum = [0]
for i in range(N):
    cumsum.append(cumsum[-1] + L[i] * C[i])
📥 入力形式
1

1行目: N (シーケンス数), K (探索対象)

2

i 行目: A_i の要素たち、最後に C_i

✅ このコードのポイント
  • line[:-1] で A_i の要素を分離
  • line[-1] で C_i を取得
  • cumsum[0] = 0 で、初期位置をセット
  • cumsum[i] = 前までの合計 + L[i] × C[i]
