二分探索と答え取得（13行）

解説

二分探索で K の所属シーケンスを見つけ、相対位置から答えを計算

left = 0
right = N

while left < right:
    mid = (left + right) // 2
    if cumsum[mid + 1] < K:
        left = mid + 1
    else:
        right = mid

idx = left
pos = K - cumsum[idx]

result_idx = (pos - 1) % L[idx]
print(A[idx][result_idx])

✅ 計算フロー
  • idx = left: K が属するシーケンス
  • pos = K - cumsum[idx]: シーケンス内での相対位置
  • (pos - 1) % L[idx]: 0-indexed の位置
  • A[idx][...]: 最終的な要素
⚠️ インデックスの注意
  • cumsum は 0-indexed
  • K は 1-indexed（ユーザー視点）
  • モジュロ前に -1 を忘れずに
