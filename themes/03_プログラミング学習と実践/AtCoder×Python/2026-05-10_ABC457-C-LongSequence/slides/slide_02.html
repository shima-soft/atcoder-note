問題文・制約・入出力例

問題の本質

大きなシーケンスを構築せずに、K番目の要素を効率的に取得する

📝 問題の説明
N個のシーケンス A_1, A_2, ..., A_N が与えられます。各シーケンス A_i について、これをシーケンス B の末尾に C_i 回繰り返して追加します。このようにして作られた長いシーケンス B の K 番目の要素（1-indexed）を求めます。
⚙️ 制約
• 1 ≤ N ≤ 2 × 10⁵
• Σ(L_i) ≤ 2 × 10⁵（全シーケンスの総長）
• 1 ≤ C_i ≤ 10⁹（繰り返し回数は最大10億）
💡 ポイント: C_i が大きいので、B 全体を構築することはできません（メモリ不足）
📌 入出力例（例1）
入力:
3 9
3 1 3 2
1 3
2 4 3
1 3 2
N=3, K=9 / A_1=[3,1,3], A_2=[2,4,3], A_3=[1,3,2] / C_1=1, C_2=3, C_3=2
出力:
3
🧮 手で追ってみる
B = [3,1,3] + [2,4,3,2,4,3,2,4,3] + [1,3,2,1,3,2]
位置1～3 | 位置4～12 | 位置13～18
B[9] は位置4～12の中の9番目 = 3
