二分探索 + 出力・計算量まとめ

ポイント

lo + (hi − lo + 1) // 2 で「右寄り mid」を使い、lo=hi になったとき答えが lo に収まる

PYTHON — 二分探索 + 出力
lo = 1
hi = max(A) + K
while lo < hi:
    mid = lo + (hi - lo + 1) // 2
    if ok(mid):
        lo = mid
    else:
        hi = mid - 1

print(lo)
探索範囲
1 〜 max(A)+K
答えの上限は全操作を i=1 に集中した値
ループ回数
≈ 61 回
log₂(2×10¹⁸) ≈ 61
判定1回の計算量
O(N)
全要素を1度スキャン
全体の計算量
O(N × 61)
N ≤ 2×10⁵ → 約 1200 万回
✅ 右寄り mid を使う理由
  • ok なら lo = mid（lo を上げる）
  • mid = (lo+hi)//2 だと lo=1, hi=2 のとき mid=1 のまま無限ループ
  • lo + (hi-lo+1)//2 なら mid=2 になり必ず進む ✓
✅ Python の実行可能上限
  • O(N log V): N=2×10⁵ × 61 ≈ 1200 万回
  • O(N log N) は N ≤ 5×10⁵ が目安なので余裕あり
  • Python でも時間制限 2 秒以内に収まる
