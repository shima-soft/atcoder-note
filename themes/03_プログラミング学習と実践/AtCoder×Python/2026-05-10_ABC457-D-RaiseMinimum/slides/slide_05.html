判定関数

「最小値 m 以上にできるか？」を O(N) で判定する

ポイント

要素ごとに必要な操作回数を切り上げ除算で計算し、合計 ≤ K なら達成可能

計算例: m = 3, A = (1, 2, 3), K = 3
i（番号） A[i]（初期値） m − A[i] 必要操作回数
1 1 2 ⌈2÷1⌉ = 2
2 2 1 ⌈1÷2⌉ = 1
3 3 0（≥ m） 0
合計操作回数 2 + 1 + 0 = 3
3 ≤ K=3 → 達成可能 ✅
m=3 の最小値は操作 K 回以内で実現できる
一般式（A[i] < m のとき）
cost(i) = ⌈(m − A[i]) ÷ i⌉
Python: (m - A[i] + i - 1) // i
⌈a ÷ b⌉ = (a + b − 1) // b（Python 整数除算で切り上げ）
🔍 計算の手順
1

A[i] ≥ m なら操作不要 → cost = 0

2

A[i] < m なら不足量 = m − A[i]

3

操作1回で i 増えるので、
必要回数 = ⌈不足量 ÷ i⌉（切り上げ）

4

全要素の合計 ≤ K なら達成可能

✅ なぜ切り上げ除算なのか
  • i=2 で A[i]=1、目標 m=4 の場合: 不足 3
  • 1回目: 1→3（+2）、2回目: 3→5（+2）
  • 2回で 5≥4 達成 → ⌈3÷2⌉ = 2 回で正しい ✓
✅ オーバーフロー対策
  • 合計が K を超えた時点で即 False を返す
  • 加算し続けると 10¹⁸ × N を超える可能性
  • Python は多倍長なので溢れないが早期終了で高速化
