用語解説

このスライドで登場した用語の読み方と概要

二分探索 にぶんたんさく / binary search

単調性がある問題で、探索範囲を半分ずつ絞り込む手法。O(log N) で答えを発見できる。「できる/できない」の境界を探すときに有効。

Wikipedia: 二分探索 🔗
単調性 たんちょうせい / monotonicity

入力が増えると出力も必ず増える（または減る）性質。二分探索が使える条件の一つ。本問では「m が大きいほど必要操作数も増える」ことが単調性。

Wikipedia: 単調関数 🔗
切り上げ除算 きりあげじょさん / ceiling division

割り算の結果を上方向に丸める演算。Python では (a + b - 1) // b で実現。⌈a ÷ b⌉ と表記する。操作回数の最小値を求めるときに使う。

Python公式: math.ceil 🔗
判定問題 はんていもんだい / decision problem

答えが Yes / No の二択になる問題。最大化・最小化問題を「○○以上/以下にできるか？」に置き換えることで判定問題に変換できる。競プロの定番テクニック。

Wikipedia: 決定問題 🔗
O 記法 オーきほう / Big-O notation

アルゴリズムの計算量（実行時間の増え方）を表す記法。O(N log V) は入力 N と値域 V に対して比例的に増えることを示す。本問では O(N × 61) ≈ O(60N)。

Wikipedia: ランダウの記号 🔗
sys.stdin.readline シス・スタンダードイン・リードライン

Python で高速に標準入力を読み込む方法。input() より数倍速く、大量の入力がある競プロで必須のテクニック。

Python公式: sys.stdin 🔗
