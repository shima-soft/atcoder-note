問題を読み解く

番号 i を選んで A[i] に i を加える — 最小値を最大化

ポイント

操作1回で加わる量は「どの番号を選ぶか」で変わる。K 回の使い道が鍵

問題文（噛み砕き版）
操作の内容
長さ N の数列 A と整数 K が与えられる。
以下の操作を 0 回以上 K 回以下 行える。
操 1〜N の好きな番号 i を選び → A[i] += i
同じ番号を 何度選んでも OK。
操作後の数列の 最小値を最大化 せよ。
💡 番号が大きいほど 1 回で増える量が大きい。
でも最小値を上げるには「足りない要素」を優先する必要がある。
制約
変数の意味と範囲
N 数列の長さ（≤ 2×10⁵）
A[i] 各要素の初期値（1 以上 10¹⁸ 以下）
K 操作回数の上限（1 以上 10¹⁸ 以下）
i 1 始まりのインデックス（1〜N）
⚠️ A[i] と K が最大 10¹⁸
→ Python の int は多倍長なので桁あふれなし。
C++ の場合は long long が必須。
入出力例
サンプルで確認
NKA答え
33(1, 2, 3)3
45(10, 1, 10, 1)7
例1 の確認:
i=1 を 2 回 → A[1]＝1+1+1＝3
i=2 を 1 回 → A[2]＝2+2＝4
数列 (3, 4, 3) → 最小値 3 ✅

例2 の確認:
i=2 を 3 回 → A[2]＝7、i=4 を 2 回 → A[4]＝9
数列 (10, 7, 10, 9) → 最小値 7 ✅
