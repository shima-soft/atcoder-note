入力処理 + 判定関数 ok(m)（15 行）

ポイント

ops が K を超えた時点で即 False を返し、無駄な加算を省く

PYTHON — 入力 + 判定関数
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
A = list(map(int, input().split()))

def ok(m):
    ops = 0
    for i in range(N):
        if A[i] < m:
            diff = m - A[i]
            cnt = (diff + i) // (i + 1)
            ops += cnt
            if ops > K:
                return False
    return True
🔍 ok(m) の処理の流れ
1

for i in range(N) で各要素を順番に確認（0始まり）

2

A[i] < m のとき、不足量 diff = m - A[i]

3

操作1回で i+1 増える（1始まりの番号 = i+1）
切り上げ: (diff + i) // (i + 1)

4

累積 ops が K を超えたら即 False（早期終了）

✅ インデックスの対応
  • 問題の i は 1 始まり、Python の range(N) は 0 始まり
  • Python の i ＝ 問題の i − 1
  • 1回の操作で加わる量 = 問題の i = i + 1
  • 切り上げ式: (diff + i) // (i+1) = ⌈diff ÷ (i+1)⌉
