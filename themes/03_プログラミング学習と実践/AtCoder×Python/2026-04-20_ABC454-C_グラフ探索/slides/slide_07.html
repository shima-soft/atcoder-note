BFS でノード1から到達可能なノードを数える

ポイント

visited フラグで二度訪問を防ぎ、sum(visited) で到達ノード数を一発で集計

# BFS
visited = [False] * (N + 1)
visited[1] = True
queue = deque([1])

while queue:
    node = queue.popleft()
    for next_node in graph[node]:
        if not visited[next_node]:
            visited[next_node] = True
            queue.append(next_node)

print(sum(visited))
📌 各行の意味
1

visited[1] = True — ノード1を「訪問済み」にしてキューへ

2

queue.popleft() — キュー先頭のノードを取り出す（O(1)）

3

未訪問の隣接ノードのみ visited=True にしてキューへ追加

4

sum(visited) — True の数 = 到達ノード数を出力

⏱️ 計算量まとめ
グラフ構築
O(M)
M本のエッジを1回追加
BFS探索
O(N+M)
各ノード・エッジを1回ずつ
N=M=3×10⁵ → Python で間に合う上限
≈ 6×10⁵ 回
Python 目安: N ≤ 10⁷ なら1秒以内 ✅
✅ deque を使う理由
  • list の pop(0) は O(N)、deque の popleft() は O(1)
  • BFS では先入れ先出しが必須 → deque 一択
