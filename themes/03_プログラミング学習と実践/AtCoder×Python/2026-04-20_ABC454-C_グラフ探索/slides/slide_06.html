コード①

入力を受け取り、グラフを組み立てる

ポイント

隣接リスト graph[a] に「a から行けるノード b」を追加していくだけ

from collections import deque

N, M = map(int, input().split())

# 隣接リスト: graph[a] に a→b の b を追加
graph = [[] for _ in range(N + 1)]
for _ in range(M):
    a, b = map(int, input().split())
    graph[a].append(b)
📌 各行の意味
1

deque をインポート（BFSのキューに使う）

2

graph = [[] for ...] — ノード番号ごとの「隣人リスト」を作る

3

交換ペア (a, b) を読み込み、graph[a].append(b) でエッジを追加

📐 例1のグラフ構築結果（N=5, M=5）
graph[1] = [2]
graph[2] = [3, 4]
graph[3] = [4]
graph[4] = []
graph[5] = [2]
✅ N+1 で確保する理由
  • アイテム番号は 1〜N（0番は使わない）
  • range(N+1) にして graph[1]〜graph[N] をそのまま使う
→ 次のスライドで BFS 本体を実装します
