このスライドで登場した用語の読み方と概要

BFS（幅優先探索） ビーエフエス・はばゆうせんたんさく

グラフを「近い順」に広がりながら探索するアルゴリズム。キュー（待ち行列）を使い、スタートから届く全ノードを効率よく発見できる。

Wikipedia 🔗
有向グラフ ゆうこうグラフ

矢印（向き付き辺）で接続されたノードの集まり。A→B の矢印があっても B→A には戻れない。今回の「交換ペア」が有向グラフの辺に相当する。

deque（両端キュー） デック

Python の collections モジュールにある両端キュー。先頭への追加・取り出しが O(1) で行えるため BFS に最適。list.pop(0) の代わりに使う。

docs.python.org 🔗
隣接リスト りんせつリスト

グラフの辺情報を「各ノードの隣人リスト」として持つ表現方法。graph[i] にノード i から行ける全ノードを格納する。N×N の隣接行列より省メモリ。

O(N+M) 記法 オーダー・エヌプラスエム

計算量の表記。N がノード数、M がエッジ数のとき、BFS は両方を1回ずつ処理するので O(N+M)。N=M=3×10⁵ なら約 6×10⁵ 回 → Python でも十分速い。
