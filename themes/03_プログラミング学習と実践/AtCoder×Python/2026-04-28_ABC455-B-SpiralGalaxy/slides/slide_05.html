PYTHON — ABC455B Spiral Galaxy
H, W = map(int, input().split())
S = []
for i in range(H):
    S.append(input())
count = 0
for h1 in range(H):
    for h2 in range(h1, H):
        for w1 in range(W):
            for w2 in range(w1, W):
                ok = True
                for i in range(h1, h2 + 1):
                    for j in range(w1, w2 + 1):
                        pr = h1 + h2 - i
                        pc = w1 + w2 - j
                        if S[i][j] != S[pr][pc]:
                            ok = False
                if ok:
                    count += 1
print(count)

📥 入力受け取り（1〜4行目）

L1 H と W を整数で取得
L2-4 H 行分の文字列をリスト S に追加。
S[0]=".#"、S[1]="#."… のように使う

🔁 4重ループで全長方形を列挙（6〜9行目）

h1,h2 開始行・終了行（h1≤h2）
w1,w2 開始列・終了列（w1≤w2）
これで全ての長方形を網羅できる

✅ 点対称チェック（10〜16行目）

長方形内の全マス (i, j) について
pr = h1+h2−i, pc = w1+w2−j を計算し
S[i][j] == S[pr][pc] を確認。
1つでも違ったら ok = False にする

➕ カウントと出力（17〜19行目）

全セルがOKなら count を +1。
最後に count を出力する
