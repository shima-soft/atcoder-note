このスライドで登場した用語の読み方と概要

点対称 てんたいしょう

ある点を中心に180°回転させたとき、元の図形とぴったり重なる性質。この問題では長方形内のマスが「中心点で折り返したペアと同じ色」であることを指す。

Wikipedia: 点対称 🔗
全探索 ぜんたんさく

考えられる全ての候補を一つひとつ試す方法。制約が小さいときに最もシンプルで確実な解き方。人がアンケートを全件読み返して答えを探すのに近い。

Wikipedia: 総当たり 🔗
ネストしたループ ネストしたループ

ループの中にさらにループが入っている構造。この問題では4重ループ（h1, h2, w1, w2）を使う。表の縦と横を全組み合わせで調べるイメージ。

input() インプット

標準入力から1行を文字列として読み込む Python の組み込み関数。AtCoderでは毎回使う基本の命令。

Python ドキュメント: input 🔗
map() マップ

リストの各要素に同じ変換を適用する関数。map(int, input().split()) で「スペース区切りの数字を整数に一括変換」できる。

Python ドキュメント: map 🔗
