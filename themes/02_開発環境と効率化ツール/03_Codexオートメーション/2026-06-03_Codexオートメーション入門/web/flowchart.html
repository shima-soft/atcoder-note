記事に戻るCodex自動化の選択フローチャート

どのCodex自動化を使う？

3つの質問で、Thread automation / Standalone automation / codex exec / GitHub Actionの候補を選びます。

1
同じ会話の文脈を残したいですか？

デプロイ見守り、長いレビュー、継続調査のように「前回の続き」が重要ならYES。

2
GitHub ActionsやCIの中で動かしますか？

PRレビュー、CI失敗調査、リリース前チェックなど、ワークフロー内で走らせるならYES。

3
GitHub上のPRやCIイベントをきっかけにしますか？

GitHubのイベントで起動するならCodex GitHub Action。自前スクリプトやログ処理ならcodex exec。
