BROWSER

Browserは「画面で確かめる」担当

一言で

Webアプリやローカル画面を開き、操作して、見た目と挙動を確認します。

向いている依頼

  • localhostを開いて確認して
  • このページの表示崩れを見て
  • スマホ幅で文字切れを見て

注意

  • ブラウザ接続や権限で失敗することがある
  • 送信や削除など影響のある操作は確認が必要
ARTIFACTS

資料系プラグインは「成果物にする」担当

Doc

Documents

文章を納品物にする。報告書、マニュアル、レビューコメント。

PPT

Presentations

話す資料にする。提案、研修、社内説明会。

XLS

Spreadsheets

数字を整理する。Excel、CSV、グラフ、数式。

CONNECTORS

Gmail・Drive・Slackは「外部情報を使う」担当

頼み方の例

  • 今日の未読メールのうち、取引先だけ要約して
  • Driveの最新資料から会議用の要点を抜き出して
  • Slackの昨日分だけまとめて

確認すること

  • どのアカウントで認証しているか
  • どのフォルダやチャンネルを読ませるか
  • 読ませてよい情報なのか
SECURITY & SITES

SecurityとSitesは「守る・公開する」担当

守

Codex Security

認可されたコードの脆弱性レビュー。差分スキャンや発見事項の修正に使います。

公

Sites

Webサイトやアプリを保存・公開。公開URLは本番公開として扱います。

CHOICE

迷ったら「成果物」と「データ源」を先に言う

資料作成

目的: 営業会議用の10枚スライドを作る
素材: このCSVと議事録
使ってほしいもの: PresentationsとSpreadsheets
確認: 表とタイトルの整合性

画面確認

目的: ローカルWeb画面の表示確認
素材: localhost:8181
使ってほしいもの: Browser
確認: 文字切れ、ボタン動作、スマホ幅

参考: OpenAI Codex Manual / Plugins、Codex Security plugin、Sites（2026年6月4日確認）
