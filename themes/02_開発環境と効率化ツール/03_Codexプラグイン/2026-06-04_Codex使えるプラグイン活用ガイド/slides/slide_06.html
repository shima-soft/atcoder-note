SECURITY & SITES

SecurityとSitesは「守る・公開する」担当

一言で

コードの安全確認と、Webサイトの保存・公開を、目的別ワークフローとして使います

守
Codex Security

認可されたリポジトリや差分を対象に、脆弱性の候補を調査し、証拠にもとづく報告を作る。

差
Diff scan

変更前後のセキュリティ退行を確認。プルリクエスト前のチェックに向いている。

直
Fix finding

1つの発見事項に絞って、最小修正と再現確認を行う。範囲を広げすぎないのがコツ。

公
Sites

Webサイト、Webアプリ、ゲームを保存・公開。デプロイURLは本番公開として扱う。

版
Save version

まずは公開せずに保存してレビュー。内容、データ、アクセス範囲を確認してから公開する。

限
Access mode

Owner/admin、workspace、customなど、誰が見られるかを公開前に決める。
