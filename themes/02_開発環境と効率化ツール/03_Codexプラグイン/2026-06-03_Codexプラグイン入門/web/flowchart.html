Codex拡張 選択フロー

いま必要なのがSkill、Plugin、App、MCPのどれに近いかを3問で整理します。

Q1. やりたいことは「毎回同じ作業手順を守らせる」ことですか？
Q2. Gmail、Drive、Slackのような外部サービスにつなぎたいですか？
Q3. チームに配る、または複数の部品をまとめたいですか？

おすすめ: Skill

まずはSKILL.mdで、作業手順や参照すべき資料を書きましょう。小さく始めるならSkillが最短です。

おすすめ: App連携

外部サービスの認証、利用条件、読めるデータ範囲を確認してから使いましょう。

おすすめ: Plugin

Skill、App、MCPなどをまとめて、チームやワークスペースに配る形に向いています。

おすすめ: MCP server

社内DB、独自API、検索ツールなどをCodexの道具として渡したい時に検討します。
